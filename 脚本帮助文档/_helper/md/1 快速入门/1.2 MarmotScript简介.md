# MarmotScript简介

## 是什么

>MarmotScript 是以 JavaScript 脚本为基础的独立生态   
>服务于SRM的后端定制开发

MarmotScript是基于JavaScript的   
1.包含额外内部功能的  
2.由process函数作为执行入口的  
3.由SRM各个功能点进行触发的  
运行时后端代码，后端运行时

## 可以做什么

### 与标准耦合的开发
* 由标准程序埋点触发脚本(旧称适配器)
* 标准功能导入(覆盖或增强标准校验器，导入器)
* 标准功能API前置后置增强(标准功能Restful接口前后逻辑改写与变动)
* RTF打印生成(覆盖标准的标签生成取数逻辑)

### 独立定制化开发
* API(发布仅属于租户的API，可由各功能菜单调用，逻辑由MarmotScript编写)
* 调度任务(定时执行的MarmotScript脚本)
* 消息队列消费者(可使用MarmotScript消费由MarmotScript生产的消息)
* 工作流(服务定义可使用MarmotScript编写)
* Excel解析和生成(MarmotScript内置了Excel读写支持，可通过API发布支持Excel导入导出)
* RTF打印生成(独立的定制化打印，取数逻辑由MarmotScript编写)

## 如何进行断点调试

当你想要进行中断debug调试的时候，需要为脚本添加一些特殊结构
(当前该功能仅在公有云DEV环境提供 2022-06-11)
```javascript
//DEBUG-zhenyun34468  /*必须在第一行*/   
function process( input ){
  let result = 1;
  debugger;   //将中断在这里
  return {result : result}
}
```

如果想看到debugger断点的结果，需要开启一个新页面，这个页面的地址需要点击调试界面扳手🔧按钮获得。页面打开后是如下图所示
