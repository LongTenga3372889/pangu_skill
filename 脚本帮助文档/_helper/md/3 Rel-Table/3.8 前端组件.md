# RelTable 配置表组件

## 说明：

配置表组件，可以在任意的页面位置嵌入一个配置化的表来展示相对应的数据。

![](../../_helper/images/rel-3.8.1.png)

## 使用

#### 1、在页面中依赖 RelTable 组件

```javascript
import RelTable from 'srm-front-boot/lib/components/RelTable';
// OR
import RelTable from '_components/RelTable';
```

ps： 需要 `srm-front-boot` 的版本 `> 1.19.0-alpha.20`

#### 2、 在需要加入配置表的位置使用

```javascript
//...
<RelTable tableCode={tableCode} />
//...
```

## API

| 属性               | 类型     | 默认值   | 是否必输 | 描述                                                         |
| ------------------ | -------- | -------- | -------- | ------------------------------------------------------------ |
| tableCode          | String   | undefied | 是       | 组件查询必须配置表code                                       |
| exportDataFlag     | Boolean  | true     | 否       | 导出数据按钮显隐                                             |
| exportTemplateFlag | Boolean  | true     | 否       | 导出模板按钮显隐                                             |
| importDataFlag     | Boolean  | true     | 否       | 导入数据按钮显隐                                             |
| canEditFlag        | Boolean  | true     | 否       | 外部控制是否可以进行新建编辑的环境变量，优先级最高           |
| showQueryBar       | Boolean  | true     | 否       | 外部控制是否显示查询区域                                     |
| showHeader         | Boolean  | true     | 否       | 外部控制是否可以显示头部内容，如果设置为false，按钮和头部标题都不显示 |
| afterSuccessAction | Function | () => {} | 否       | 操作成功后调用方法                                           |
| queryParams        | Object   | {}       | 否       | 外部传入查询参数，优先级高于查询框                           |
