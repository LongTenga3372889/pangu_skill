# 动作

本质是给配置表生命周期挂上一些行为，这个行为是以MarmotScript支持的

## 条件类
- 前端查询前

  在此触发点支持修改Page查询前的查询条件
  > 脚本代码：入参结构参考：`input:{"condition":{"code":{"opr":"=","v":"test"}}}` 出参结构：`{"condition":{"code":{"opr":"=","v":"test"}}}`

  示例：
  ```javascript
    function process(input) {
      input.condition.code = { opr: "=", v: "2" };
      return input;
    }
  ```

### 触发

> 脚本代码：入参为：`input:{records:[{行数据}]}` 出参：`{records:[{行数据}]}`

- 前端查询

   >注意，前端查询触发点在Rel统一值集翻译前，因此在这里操作值集翻译会被Rel默认翻译覆盖

  界面查询或者代码中page查询，在数据展示前，可在这挂脚本操作Rel返回的数据

- 后端查询

  Java：RelTableHelper/LocalRelTableHelper #selectByCondition

  MarmotScript：@M/v1/object #query #fetchById

  代码中查询数据，获得数据前走进此触发点

- 数据导入

  >此触发点还会依次走过触发点 【保存前】->【保存后】

  配置表菜单的数据导入，会走到此触发点

- 保存前

  数据入库前

- 保存后

  数据insert完成，事务未提交。此时who字段，主键都已有值

- 删除

  数据删除前
