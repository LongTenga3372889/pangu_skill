## Java

引入依赖
```java
<dependency>  
    <groupId>org.srm.boot</groupId>  
    <artifactId>srm-boot-adaptor</artifactId>  
</dependency> 
```



- RelTableHelper：Feign调用
- LocalRelTableHelper：客户端，可加入当前事务

>**class  RelTableHelper**    / **class LocalRelTableHelper**

------------

>**selectByCondition**
>查询指定条件的配置表数据  
> ` public static <T> List<T> selectByCondition(Long tenantId, String tableCode, T condition)`  
> **Parameters:**  
> tenantId - 租户Id  
>tableCode - 配置表编码  
>condition - 查询条件  
>**Returns:**
>查询出的结果集

------------

>**create**
>往指定的配置表新增数据，隐式维护 id字段  
>` public static <T> T create(Long tenantId, String tableCode, T t)`  
>**Parameters:**  
>tenantId - 租户Id  
>tableCode - 配置表编码  
>t - 新增数据实体  
>**Returns:**
>新增数据实体

------------

>  **update**
>  更新指定条件配置表的数据  
>` public static <T> T update(Long tenantId, String tableCode, T t)`  
>**Parameters:**  
>tenantId - 租户Id  
>tableCode - 配置表编码  
>t - 更新数据实体  
>**Returns:**
>更新数据实体

------------
>**updateOptional**
>更新指定字段的值  
>`public static <T> T updateOptional(Long tenantId, String tableCode, T t, String... options) `  
>**Parameters:**  
>tenantId - 租户Id  
>tableCode - 配置表编码  
>t - 更新数据实体  
>options - 目标字段数组  
>**Returns:**
>更新数据实体

------------

>**remove**
>删除指定配置表的数据 --实则是根据 id删除  
>`public static <T> void remove(Long tenantId, String tableCode, T t)`  
>**Parameters:**  
>tenantId - 租户Id  
>tableCode - 配置表编码  
>t - 需删除的数据实体
