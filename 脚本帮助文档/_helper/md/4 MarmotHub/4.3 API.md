# API
将Java业务代码或sql转移至土拨鼠脚本中实现，根据API配置信息自动生成请求地址，实现API的动态发布。该api后端执行时外层包裹事务，报错统一回滚。  
## 土拨鼠API配置
1. api编码：全局唯一即可。  
2. 所属租户：用于指定该API适用租户。  
3. 关联脚本：关联土拨鼠独立脚本。  
4. 描述信息：用于描述接口信息（带上需求号）。  
5. 请求地址：自动生成禁用编辑（后续根据自动生成的请求地址使用即可）。  
## 土拨鼠API使用
script脚本的input中会有url上面所有的参数、body里面所有数据以及请求头中的所有参数。  
注意：script脚本input中body参数均为字符串类型需要自行根据约定转换后使用。  
API发布可以搭配使用debugger，进行前后端联调。  
## 适配器返回值说明
脚本return中支持三个返回值  
1. header：header中的参数赋值到response的header中。  
2. body：用于返回数据给前端使用（注意！ body支持两种返回格式）  
   - buffer流，用于实现导出、打印等文件下载类接口，注意下载文件大小不要超过30mb  
   - string，用于返回执行结果类接口  
3. httpStatus: http状态码，仅允许使用200-500之间的状态码（默认200）。

## 脚本案例
```javascript
function process(input) {
	STD.Logger.error("input中body的参数：" + input.body);
	STD.Logger.error("input中method的参数：" + STD.SAFE_JSON.stringify(input.method));
	STD.Logger.error("input中parameter的参数：" + STD.SAFE_JSON.stringify(input.parameter));
	STD.Logger.error("input中header参数：" + STD.SAFE_JSON.stringify(input.header));
    STD.Logger.error("input中url参数,用于获取请求路径上的参数：" + STD.SAFE_JSON.stringify(input.requestURI));
	let method = input.method;
	let body = STD.SAFE_JSON.parse(input.body);
	let parameter = input.parameter;
	let header = input.header;
	let result;
	if (method == "GET") {
	//分页查询
		let page = {
			"page": parameter.page,
			"size": parameter.size
		};
		result = STD.QueryBlock.selectPage('MARMOT_API_TEST_QUERY', parameter, page);
	} else if (method == "POST") {
	//修改
		result = STD.Database.table("docf_node_table_opr").updateOptional(body, "table_code", "table_pk");
	} else if (method == "PUT") {
	//新增
		result = STD.Database.table("docf_node_table_opr").insert(body);
	} else if (method == "DELETE"){
	//删除
		result = STD.Database.table("docf_node_table_opr").deleteByPrimary(body);
	}
	return {
        "body": STD.SAFE_JSON.stringify(result),//responsebody前端接收的参数，必须返回
        "header":{test:"test"},//可以进行覆盖和添加response头信息，非必需返回
        "httpStatus" : 200 //支持200-500之间的response状态码，非必需返回
	}
}
```

## 脚本案例2-重定向
```javascript
function process(input) {
    
    //API 功能允许变动 response的body,header,httpStatus 三个部分
    //可以实现cookie放置、重定向等功能
    
	return {
        "body": undefined, //没有body
        "header":{location:"https://www.baidu.com"},//302重定向规范，header location写入目标地址
        "httpStatus" : 302 //重定向
	}
}
```
## 脚本案例3-上传文件
```javascript
function process({ method, parameter={}, header={}, body='' ,formData={}}) {
    //formData中包含了postman中的form-data里的所有参数(包含文件)
    //multipartParameterNames代表form-data中的非文件参数
    //multipartFiles代表文件参数
    //multipartFiles中每个文件的key是一个数组,数组中的每一个value文件包含bytes(文件流),name(文件名),contentType(文件头)三个参数
  STD.Logger.warn("参数{}",formData.multipartParameterNames.info[0])
  STD.Logger.warn("文件{}",formData.multipartFiles.file[0].name)
  return {
      //获取到的文件转换成buffer后可以进行一系列操作
    body: new Buffer(formData.multipartFiles.file[0].bytes),
    header: {
      "Content-Type": "application/pdf",		//根据你要下载的文件类型
      "Content-Disposition": "attachment;filename=11123.pdf"	//文件名自定
    } //可选，如果需要放置 response header
  };
}
```

# 总结
1. 支持的请求方式：get、put、patch、delete、post、trace  
2. input参数中会携带请求方式参数，可自行根据需要对不同请求方式进行处理。  
3. input中包含header、body、parameter、formData中所有参数。  
4. return中如果存在header的返回值，会将header赋值到response的header中。注意header中key、value仅支持string类型。  
5. return中body要求用于buffer或string格式进行返回。
