# 通用文件下载按钮，与API发布配合使用

***

## `<MarmotDownloadButton />`

#### 描述

*   该按钮根据所给API下载文件

*   该按钮需要从srm-front-boot引用

*   下载方法使用的是hzero-front/src/services/api/file.ts文件中downloadFileByAxios，并进行了以下两点的修改：

1.  该下载按钮自动处理后端脚本业务性错误：如：\[ 该文件不可下载 ]

2.  在downloadFileByAxios中调整content-disposition获取文件名方式，使其可以传输中文

#### 前端按钮组件相关参数

| **参数名**         | **必输**      | **类型**         | **默认值** | **说明**                                                                       |
| --------------- | ----------- | -------------- | ------- | ---------------------------------------------------------------------------- |
| api             | 是           | string         | 空       | 接口地址                                                                         |
| isButton        | 否           | boolean        | true    | 显示为按钮还是a标签                                                                   |
| displayName     | 否           | string         | 导出      | 按钮名                                                                          |
| defaultFileName | 前端或脚本必须有一个给 | string         | 空       | 下载文件名，前端传值 "测试.xlsx", 也可以后端header中传入值，encodeURIComponent("filename=测试.xlsx") |
| style           | 否           | object         | 空       | 外部传入的样式参数                                                                    |
| queryParams     | 否           | array\<object> | \[]     | 下载文件请求的查询参数，参数格式为：\[{ name: '', value: '' }]]                                |

#### 前端使用示例

```react
import MarmotDownloadButton from 'srm-front-boot/lib/components/MarmotDownloadButton';

<MarmotDownloadButton api='/marmot/v1/30/marmot-api/cesi' />

```

#### MarmotScript中使用示例

```javascript
//let bytes = XLSX_STYLE.write(workbook,{type:"buffer"});
let bytes=Buffer.from('{"h":"我是一个json"}')
// header中无法传中文需要通过encodeURIComponent转码
const filename = encodeURIComponent("filename=测试.json");

return{
  body:bytes,
  header:{'content-disposition': filename}
}
```

### 注意：

1.  文件名可以前端通过defaultFileName传，也可以通过脚本中header的content-disposition传，优先级：脚本 > 前端

2.  当由脚本传入文件名时，有中文或特殊字符时，必须要进行encodeURIComponent转码
