# 跨租户 CodeBlock 调用

## 概述

支持平台租户调用其他租户的 CodeBlock，实现跨租户脚本复用和代码共享。

## 功能特性

- **简单易用**: 通过冒号分隔符实现跨租户调用
- **向后兼容**: 完全兼容原有本租户调用方式
- **权限控制**: 仅平台租户(SRM)允许跨租户调用，确保数据安全

## 使用方式

### 1. 调用本租户 CodeBlock（原有方式）

```javascript
_code_block.execute("my-code");
```

### 2. 跨租户调用 CodeBlock（新功能）

```javascript
_code_block.execute("SRM-HCZN:my-code");
```

## 语法格式

```
_code_block.execute("租户编号:代码块编号");
```

### 参数说明

| 参数 | 说明 | 示例 |
|------|------|------|
| 租户编号 | 目标租户的编号 | SRM-HCZN, TEST |
| 代码块编号 | CodeBlock的唯一标识 | my-code, common-logic |
| 分隔符 | 冒号 `:` | 必须使用英文冒号 |

## 使用示例

### 示例 1：基础跨租户调用

```javascript
// 调用租户 SRM-HCZN 的代码块
var hcLogic = _code_block.execute("SRM-HCZN:business-logic");

// 调用租户 TEST 的测试代码块
var testCode = _code_block.execute("TEST:test-helper");
```

### 示例 2：混合使用场景

```javascript
// 本租户的通用代码
var common = _code_block.execute("common-utils");

// 跨租户调用特定业务逻辑
var specific = _code_block.execute("SRM-HCZN:hc-specific-logic");

// 组合使用
function processData(data) {
    var validated = common.validate(data);
    var result = specific.process(validated);
    return result;
}
```

### 示例 3：动态租户调用

```javascript
// 根据配置动态选择租户
var targetTenant = getTargetTenant(); // 返回 "SRM-HCZN"
var codeBlock = "business-logic";

var logic = _code_block.execute(targetTenant + ":" + codeBlock);
```

## 数据库要求

### CodeBlock 数据结构

确保 `sada_adaptor_code_block` 表中存在对应记录：

```sql
-- 查询示例
SELECT * FROM sada_adaptor_code_block 
WHERE tenant_num = 'SRM-HCZN' 
  AND block_code = 'business-logic';
```

### 表结构要求

| 字段 | 类型 | 说明 |
|------|------|------|
| tenant_num | VARCHAR | 租户编号 |
| block_code | VARCHAR | 代码块编号 |
| content | TEXT | 代码内容 |
| description | VARCHAR | 描述（可选） |

## 工作原理

### 1. 参数解析

```java
// 原有调用：_code_block.execute("my-code")
// 解析结果：tenantNum = 当前租户, code = "my-code"

// 跨租户调用：_code_block.execute("SRM-HCZN:my-code")
// 解析结果：tenantNum = "SRM-HCZN", code = "my-code"
```

### 2. 缓存机制

系统使用 `CentralizedCache` 缓存 CodeBlock，缓存key格式为：
```
租户编号|代码块编号
```

例如：
- 本租户缓存：`CURRENT_TENANT|my-code`
- 跨租户缓存：`SRM-HCZN|my-code`

缓存不会冲突，各自独立。

### 3. 异常处理

```javascript
// 代码块不存在时抛出异常
try {
    _code_block.execute("INVALID-TENANT:nonexistent");
} catch (e) {
    // e.message: "MarmotScript CodeBlock not found [INVALID-TENANT:nonexistent]"
}
```

## 权限控制

### 平台租户限制

**重要**: 跨租户调用功能**仅限平台租户(SRM)**使用，普通租户无法跨租户调用。

```javascript
// ✅ 平台租户(SRM)可以跨租户调用
_code_block.execute("SRM-HCZN:my-code");

// ❌ 普通租户无法跨租户调用，会抛出 SecurityException
_code_block.execute("SRM-HCZN:my-code"); 
// 错误信息: "无权跨租户调用CodeBlock，当前租户: SRM-HCZN"
```

### 权限验证逻辑

```java
// 在 ForScriptCodeBlock.java 中的权限控制
if (code.contains(":")) {
    String[] parts = code.split(":", 2);
    targetTenantNum = parts[0];
    targetCode = parts[1];
    
    // 权限控制：仅平台租户(SRM)允许跨租户调用
    if (!"SRM".equals(currentExecutionTenantNum)) {
        throw new SecurityException("无权跨租户调用CodeBlock，当前租户: " + currentExecutionTenantNum);
    }
}
```

### 权限判断标准

- **平台租户**: `tenantNum = "SRM"`
- **普通租户**: `tenantNum` 为其他值（如 "SRM-HCZN", "TEST" 等）

### 使用场景建议

| 租户类型 | 本租户调用 | 跨租户调用 | 说明 |
|----------|------------|------------|------|
| 平台租户(SRM) | ✅ 允许 | ✅ 允许 | 可以访问所有租户的CodeBlock |
| 普通租户 | ✅ 允许 | ❌ 禁止 | 只能访问本租户的CodeBlock |

## 注意事项

### ⚠️ 安全考虑

1. **权限控制**: 仅平台租户可跨租户调用，防止数据泄露
2. **数据隔离**: 普通租户无法访问其他租户的敏感数据
3. **业务合规**: 确保跨租户操作符合业务安全策略

### ⚠️ 性能考虑

1. **缓存机制**: 系统会缓存 CodeBlock，跨租户调用性能良好
2. **网络开销**: 如果 CodeBlock 包含远程调用，需考虑网络延迟
3. **内存使用**: 缓存会占用内存，注意缓存大小

### ⚠️ 最佳实践

1. **明确租户**: 调用时明确指定目标租户，避免混淆
2. **文档记录**: 记录跨租户依赖关系，便于维护
3. **错误处理**: 做好异常处理和降级方案
4. **监控告警**: 监控跨租户调用的性能和成功率

## 常见问题

### Q1: 如何判断代码块是否存在？

```javascript
try {
    var content = _code_block.execute("TENANT:code");
    // 存在，可以使用
} catch (e) {
    // 不存在，处理异常
    _log.error("CodeBlock not found: " + e.message);
}
```

### Q2: 可以跨租户调用系统级 CodeBlock 吗？

可以，只要在 `sada_adaptor_code_block` 表中存在对应记录即可。

### Q3: 跨租户调用有性能影响吗？

基本没有，因为：
- 使用相同的缓存机制
- 数据库查询方式相同
- 只是参数解析逻辑不同

### Q4: 如何回滚跨租户调用？

如果需要回滚，只需修改代码：
```javascript
// 改回本租户调用
_code_block.execute("my-code");  // 去掉 "TENANT:" 前缀
```

## 扩展建议

如果需要更严格的权限控制，可以考虑：

```java
// 增强版（需要权限控制时）
@MemorySafe
public String executeWithPermission(String code){
    String currentExecutionTenantNum = getCurrentExecutionTenantNum();
    String targetTenantNum = currentExecutionTenantNum;
    String targetCode = code;
    
    if (code.contains(":")) {
        String[] parts = code.split(":", 2);
        targetTenantNum = parts[0];
        targetCode = parts[1];
        
        // 权限验证
        if (!hasCrossTenantPermission(currentExecutionTenantNum, targetTenantNum)) {
            throw new SecurityException("无权访问租户 " + targetTenantNum + " 的CodeBlock");
        }
    }
    
    CodeBlock codeBlock = CentralizedCache.getCodeBlock(targetTenantNum, targetCode);
    Assert.notNull(codeBlock,"MarmotScript CodeBlock not found ["+code+"]");
    return codeBlock.getContent();
}
```
