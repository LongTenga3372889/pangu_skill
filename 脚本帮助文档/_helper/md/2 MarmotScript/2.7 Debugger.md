# Debugger

1、在需要debugger的代码的第一行新增DEBUG标识以及在代码中打上debugger

```javascript
//DEBUG-登录名   如 ：

//DEBUG-zhenyun30212
function process( input ){
  debugger
   var a = 1;
   var b = 2;
   var c = 3;
   var d = a+b;
   var e = a*c;
   return { "result":"hello debug!"}
}

```

（注：这里的debugger不会影响正常运行，只是起到一个断点标识的作用）

2、点击小扳手，按照提示操作获取到当前登录名的debugger地址并粘贴至浏览器的新标签栏中。

![](../../_helper/images/image_BbpWCHku2D.png)



3、若遇到打不开的情况（如下图）请按F12呼出控制台后 右键【刷新】按钮强制清理缓存

（正常打开页面的朋友请跳过这步）

4、正常进入debugger页面后，页面是这样的

![](../../_helper/images/image_09rQkSas0z.png)



5、点击脚本编辑页面的debug按钮，若一直在转圈则代表成功进入断点

![](../../_helper/images/image_uegjcoGbkg.png)



6、切换到debugger页面，可以看到断点已经进入到代码中的debugger处。

![](../../_helper/images/image_PJvpyZYZxv.png)



7、如果是在非脚本编写页面进行debug如：

&#x20;Java代码中调用的埋点代码

API发布/挂载的代码

EXCEL数据导入的代码

消费时执行的脚本代码

............等等

&#x20;【所有】执行marmotJs脚本的地方，全部可以以此方式进入断点调试（仅在dev、test环境生效），只需要将第一步中的标识打好并保存到脚本中即可。

（注意，非必要请不要随便在别人的代码中打上自己的登录名标记）
