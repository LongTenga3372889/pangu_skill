# ECMAScript Enhancement

> MarmotScript包含如下的对ES的增强   
> (包含且仅包含本部分，ES版本为2022)

### 数组增强

#### distinct()
示例：
```javascript
let arr1 = [1,2,3,4,1,2,3,4,4,3,2,1];
return arr1.distinct();
```

输出：[1,2,3,4]


#### groupingBy(keyFunc, valueFunc)

输入：

| 参数名       | 必输 | 类型       | 默认值    | 说明          |
| --------- | --- | -------- | ------ | ----------- |
| keyFunc   | 是  | function | 空      | 返回分类依据的key值 |
| valueFunc | 否  | function | 返回整个对象 | 返回结果的value值 |

*示例1：*

```javascript
let arr3 = [
    {a:1,b:3},
    {a:1,b:4},
    {a:2,b:5}
  ];
return arr3.collectors().groupingBy(x => x.a, null);
```

输出：

{

"1" : \[{a:1,b:3}, {a:1,b:4}],

"2" : \[{a:2,b:5}]

}

*示例2：*

```javascript
let arr3 = [
    {a:1,b:3},
    {a:1,b:4},
    {a:2,b:5}
  ];
return arr3.collectors().groupingBy(x => x.a, x => x.b);
```

输出：

{

"1" : \[3, 4],

"2" : \[5]

}

#### toMap(keyFunc, valueFunc, mergeFunc)

输入：

| 参数名       | 必输 | 类型       | 默认值 | 说明              |
| --------- | --- | -------- | --- | --------------- |
| keyFunc   | 是  | function | 空   | 返回结果的key值       |
| valueFunc | 是  | function | 空   | 返回结果的value值     |
| mergeFunc | 是  | function | 空   | 相同key的value覆盖策略 |
示例：
```javascript
let arr3 = [
    {a:1,b:3},
    {a:1,b:4},
    {a:2,b:5}
  ];
  
return arr3.collectors().toMap(x => {return x.a;}
                             , x => {return x.b;}
                             , (oldValue, newValue) => {return newValue;});
```

输出：

{

"1" :  "4",

"2" : "5"

}
