# JWT工具
> OTHER.JWT_TOOL、_sbss_jwt_tool
> JWT令牌的校验与生成

## 概念

> JWT（JSON Web Token）是一个开放标准（RFC 7519），定义了一种紧凑的、自包含的方式，用于在各方之间安全地传输信息。

本工具提供 **JWT 令牌的校验**和**生成**能力，支持 RSA 非对称签名（RS256）和 HMAC 对称签名（HS256）。

## 方法列表

| 方法 | 功能 | 支持算法 |
|------|------|---------|
| `getInfoFromToken(token, algorithm, key)` | 验证 JWT 并解析 payload | RS256/384/512、HS256/384/512 |
| `validate({token, algorithm, key})` | 同上（解构参数风格） | 同上 |
| `signToken(payloadJson, algorithm, key)` | 生成 JWT 令牌 | RS256、HS256 |
| `sign({payload, algorithm, key})` | 同上（解构参数风格） | RS256、HS256 |

## 引入

### 令牌验证

```javascript
// 校验 JWT 令牌，返回 payload 字符串
var payload = OTHER.JWT_TOOL.getInfoFromToken(token, "RS256", publicKey);
// payload → '{"sub":"user001","role":"admin","exp":1700000000}'

// 同样支持解构参数
var payload = OTHER.JWT_TOOL.validate({
    token: token,
    algorithm: "HS256",
    key: "my-hmac-secret"
});
```

### 令牌生成（RS256）

```javascript
// 生成 RS256 签名的 JWT
// key 可以是 PEM 格式私钥或纯 Base64 PKCS#8 私钥
var privateKey = `-----BEGIN RSA PRIVATE KEY-----
MIIEpAIBAAKCAQEA...
...
-----END RSA PRIVATE KEY-----`;

var token = OTHER.JWT_TOOL.signToken(
    JSON.stringify({
        sub: "user001",
        role: "admin",
        tenantNum: "ZK001",
        exp: Math.floor(Date.now() / 1000) + 3600,
        iat: Math.floor(Date.now() / 1000)
    }),
    "RS256",
    privateKey
);
// token → header.payload.signature（三段式 Base64Url）
```

### 令牌生成（HS256）

```javascript
// 生成 HS256 签名的 JWT
var token = OTHER.JWT_TOOL.sign({
    payload: JSON.stringify({sub: "user001", name: "张三"}),
    algorithm: "HS256",
    key: "my-hmac-secret"
});
```

### 生成 → 验证闭环

```javascript
// 1. 生成
var token = OTHER.JWT_TOOL.signToken(
    JSON.stringify({sub: "test", role: "admin"}),
    "RS256",
    privateKeyStr
);

// 2. 用公钥验证（复用已有能力）
var payload = OTHER.JWT_TOOL.getInfoFromToken(token, "RS256", publicKeyStr);
// payload → '{"sub":"test","role":"admin"}'
```

## 密钥格式说明

RS256 签名使用 RSA 私钥，支持以下输入格式：

| 格式 | 识别方式 | 示例 |
|------|---------|------|
| PKCS#8 PEM | `-----BEGIN PRIVATE KEY-----` | Java 标准格式 |
| PKCS#1 PEM | `-----BEGIN RSA PRIVATE KEY-----` | OpenSSL 传统格式 |
| PKCS#8 纯 Base64 | 无 PEM 头尾 | SDK 直出格式 |

引擎自动检测三种格式，无需用户手动转换。

## 安全注意事项

- 私钥通过**脚本输入参数**传入，请确保不落日志
- 建议为 `signToken` 加上 `@TrustfulOnly` 保护（仅限可信脚本调用）
- 引擎不做 payload 内容校验，调用方负责构造合法 claims
- 暂不支持需要密码的加密私钥
