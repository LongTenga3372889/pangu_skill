##### OTHER.JWT_TOOL  JWT 令牌工具

> JWT（JSON Web Token）令牌的校验与生成工具。
> 验证支持：RS256/RS384/RS512、HS256/HS384/HS512
> 生成支持：RS256、HS256

**令牌验证**

```javaScript
// 方式一：位置参数
OTHER.JWT_TOOL.getInfoFromToken(token, algorithm, key);

// 方式二：解构参数
OTHER.JWT_TOOL.validate({token, algorithm, key});
```

**令牌生成（RS256 / HS256）**

```javaScript
// 方式一：位置参数
OTHER.JWT_TOOL.signToken(payloadJson, algorithm, key);

// 方式二：解构参数
OTHER.JWT_TOOL.sign({payload, algorithm, key});
```

**参数说明**

| 参数 | 类型 | 说明 |
|------|------|------|
| `token` | String | JWT 令牌字符串（三段式） |
| `payloadJson` / `payload` | String | 自定义 claims 的 JSON 字符串（如 `{"sub":"user001","role":"admin"}`） |
| `algorithm` | String | 签名算法：RS256 / RSA256、HS256 / HMAC256（验证时还支持 RS384/RS512/HS384/HS512） |
| `key` | String | RS256：RSA 私钥（支持 PKCS#8 PEM、PKCS#1 PEM、纯 Base64），HS256：HMAC 密钥字符串 |

**示例**

```javaScript
// == 生成 RS256 JWT ==
var privateKey = "-----BEGIN RSA PRIVATE KEY-----\nMIIEpA...\n-----END RSA PRIVATE KEY-----";
var token = OTHER.JWT_TOOL.signToken(
    JSON.stringify({sub: "user001", role: "admin", exp: Math.floor(Date.now()/1000) + 3600}),
    "RS256",
    privateKey
);

// == 验证 RS256 JWT ==
var payload = OTHER.JWT_TOOL.getInfoFromToken(token, "RS256", publicKeyStr);
// payload → {"sub":"user001","role":"admin","exp":...}

// == 生成 HS256 JWT ==
var token = OTHER.JWT_TOOL.sign(
    {payload: JSON.stringify({sub: "user001"}), algorithm: "HS256", key: "my-secret"}
);
```
