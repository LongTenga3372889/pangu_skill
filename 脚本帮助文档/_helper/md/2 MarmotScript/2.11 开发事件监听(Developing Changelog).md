# 开发事件监听(Developing Changelog)
Marmot生态相关数据绑定的 ***相关数据(配置表)*** 保存后动作。

### 适用于
开发事件监听和收集，例如某开发组收集脚本保存事件，用于管理目的

### 作用于
- 独立脚本(marmot_script_library)
- RTF填充(marmot_template_management)
- Topic消费端(marmot_queue_consumer)
- API(marmot_api_publish)
- 功能API挂载(marmot_api_rewrite)
- 功能数据导入(marmot_data_import)
- 调度(marmot_scheduler)
- 代码块(sada_adaptor_code_block)
- queryBlcok(sada_adaptor_query_block)

### 使用方式
1.找到脚本编码为SADA_CHANGE_LOG_CENTER的独立脚本  
2.编辑脚本内容，并根据Body传入的类型判断进行何种操作
示例：
```javascript
function process({ method, parameter = {}, header = {}, body = "" }) {
  STD.Logger.info("SADA_CHANGE_LOG_CENTER start with input body : {}", body);
  let bodyObj = STD.SAFE_JSON.parse(body);
  switch (bodyObj.type) {
    case "marmot_script_library":
      operationLibrary(STD.SAFE_JSON.parse(bodyObj.content));  
      break;
    case "marmot_template_management":
      break;
    case "marmot_queue_consumer":
      break;
    case "marmot_api_publish":
      break;
    case "marmot_data_import":
      break;
    case "marmot_api_rewrite":
      break;
    case "marmot_scheduler":
      break;
    case "sada_adaptor_code_block":
      break;
    case "sada_adaptor_query_block":
      break;
    default:
      STD.Logger.info("unknown type body : {}", body);
  }
}

function operationLibrary(input) {
    return "hello world";
}
```
```javascript
body参数：
{
    type:"changelog类型",           //配置表类型
    content:"records的json字符串"   //配置表保存内容
}
```
