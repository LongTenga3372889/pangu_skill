# text 富文本清洗工具
> summary: 富文本清洗工具，提供clean方法移除富文本中的指定HTML标签
> 引用路径: @M/v1/text
富文本清洗工具

**引入**
```javascript
  let _text_clean = require("@M/v1/text");
```

***
### clean
富文本清洗标签

```javascript
    let _text_clean = require("@M/v1/text");
    // clean方法参数只有两个：
    // 第一个参数是富文本，类型只能是字符串；
    // 第二个参数是标签列，可以是数组类型，也可以是字符串类型(多个类型中用逗号分隔)。
    let text = _text_clean.clean("<p>您好</p>",["<p>","</p>"]);
    // 形式二：let text = _text_clean.clean("<p>您好</p>","<p>,</p>");
```
