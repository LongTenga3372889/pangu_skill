# Image 图片缩放工具
> summary: 图片缩放工具，提供resizeImage方法对图片进行缩放并返回buffer
> 引用路径: @M/v1/image
图片缩放等功能。

**引入** 
```javascript
let imageUtil = require("@M/v1/image");
```


## 图片缩放

#### 描述

*   图片缩放并上传到指定的uuid，buffer 必须是Java 支持的 有符号 byte 组成的 byte[]

#### 名称

*   resizeImage

#### 入参

| **参数名**    | **必输** | **类型**  | **默认值** | **说明**        |
| ---------- |--------|---------|---------|---------------|
| buffer     | 是      | byte[]  | 空       | 文件buffer      |
| height     | 否      | int     | 0       | 期望图片的高        |
| width     | 否      | int     | 0       | 期望图片的宽        |
| padding     | 否      | boolean | true    | 是否留白          |

#### 使用示例

```javascript

  let imageUtil = require("@M/v1/image");
```
