# signature 签名生成
> summary: 签名生成工具，通过MarmotBridge调用signature_utils生成签名图片Buffer
> 引用路径: @M/v1/signature

**引入**
```javascript
let signature = require("@M/v1/signature");
```

***

## generateSignatureBuffer

生成签名图片Buffer

#### 入参

| **参数名** | **必输** | **类型** | **默认值** | **说明** |
| --------- | ------ | ------ | ------- | ------ |
| content | 是 | string | 空 | 签名内容 |
| width | 否 | number | 空 | 图片宽度 |
| height | 否 | number | 空 | 图片高度 |

#### 使用示例

```javascript
function process(input) {
    let signature = require("@M/v1/signature");
    let buffer = signature.generateSignatureBuffer({
        content: "张三",
        width: 200,
        height: 100
    });
    return { result: buffer };
}
```

#### 返回结果示例

```json
// 返回 PNG 签名图片的 Buffer
```
