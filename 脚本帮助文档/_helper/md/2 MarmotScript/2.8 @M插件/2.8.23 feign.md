# feign 服务调用
> summary: 基于Feign的跨服务HTTP调用，支持GET/POST/PUT/DELETE
> 引用路径: @M/v1/feign-client2
服务间调用工具
>>feign属于涉跨服务调用操作，单次操作超时时间为60秒，不可更改
>
>>当返回body里有failed = true时会抛出SimpleException异常，但不会发送企微消息

**引入**
```javascript
let feignClient = require("@M/v1/feign-client2").selectClient({serverId:"srm-adaptor"});
//serverId为服务名，例如srm-adaptor
```
***

* [doGet](#doGet)
* [doPost](#doPost)
* [doPut](#doPut)
* [doDelete](#doDelete)

### doGet
发送get请求

| **参数名**     | **必输** | **类型** | **默认值** | **说明**                     |
| --------------- | ------ | ------ | ------- | -------------------------- |
| path | 是      | string | 空       | 调用路径|

```javascript
feignClient.doGet({
    path:"/v1/adaptor-test-case"
});
```
***
### doPost
发送post请求

| **参数名**     | **必输** | **类型** | **默认值** | **说明**                     |
| --------------- | ------ | ------ | ------- | -------------------------- |
| path | 是      | string | 空       | 调用路径|
| body | 是      | object | 空       | 请求体|

```javascript
feignClient.doPost({
    path:"/v1/adaptor-test-case",
    body:{}
});
```
***
### doPut
发送put请求

| **参数名**     | **必输** | **类型** | **默认值** | **说明**                     |
| --------------- | ------ | ------ | ------- | -------------------------- |
| path | 是      | string | 空       | 调用路径|
| body | 是      | object | 空       | 请求体|

```javascript
feignClient.doPut({
    path:"/v1/adaptor-test-case",
    body:{}
});
```
***
### doDelete
发送delete请求

| **参数名**     | **必输** | **类型** | **默认值** | **说明**                     |
| --------------- | ------ | ------ | ------- | -------------------------- |
| path | 是      | string | 空       | 调用路径|
| body | 否      | object | 空       | 请求体|

```javascript
feignClient.doDelete({
    path:"/v1/adaptor-test-case"
//  , body:{}     //可不填
});
```
