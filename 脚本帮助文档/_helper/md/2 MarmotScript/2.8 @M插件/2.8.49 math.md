## 基础运算

### 加（plus）

**描述**

*   大数字加法，支持string/number/BigNumber类型输入

**名称**

*   plus

**入参**

| **参数名**  | **必输** | **类型**            | **默认值** | **说明**    |
| ------- | ------ | ----------------- | ------- | --------- |
| n1      | 是      | string/number/BigNumber | 空       | 第一个数字   |
| n2      | 是      | string/number/BigNumber | 空       | 第二个数字   |
| options | 否      | object            | {}      | 配置选项，strict控制返回类型 |

#### 使用示例

```javascript
function process(input) {
    let math = require("@M/v1/math");
    
    let result = math.plus("0.1", "0.2");
    STD.Logger.info("result: {}", result); // 0.3
    
    // 使用strict模式返回BigNumber
    let bigResult = math.plus("0.1", "0.2", { strict: true });
    
    return { result: result };
}
```

*   abs

**入参**

| **参数名**  | **必输** | **类型**            | **默认值** | **说明**    |
| ------- | ------ | ----------------- | ------- | --------- |
| n1      | 是      | string/number/BigNumber | 空       | 数字       |
| options | 否      | object            | {}      | 配置选项    |

#### 使用示例

```javascript
function process(input) {
    let math = require("@M/v1/math");
    
    let result = math.abs("-5");
    
    STD.Logger.info("result: {}", result); // 5
    
    return { result: result };
}
```
