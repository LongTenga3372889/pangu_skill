# customize 页面个性化支持工具
> summary: 页面个性化支持工具，提供单元校验和个性化字段获取功能
> 引用路径: @M/v1/customize

这是一些可以在服务端使用的页面个性化工具   
当前仅包含按单元校验对象数据功能

**引入**

```javascript
let user = require("@M/v1/customize");
```

***

### 按单元校验

**描述**

* 该逻辑与Java中完全一致，只是代理

**名称**

* unitValidate

**入参**

| 参数名         | 必输  | 类型     | 默认值 | 说明                     |
|-------------|-----| ------ | --- |------------------------|
| data | yes | {} | 空   | 要校验的单元和数据形成的key:value对 |
| throwOnException      | no  | {} | 空   | 校验不通过是否抛出异常            |

**使用示例**

```javascript
const customize = require("@M/v1/customize");
const result = customize.unitValidate({
    data: {
        "SINV.SUPPLIER_DELIVERY.DETAIL.HEADER": asnHeader,
        "SINV.SUPPLIER_DELIVERY.DETAIL.HEADERSHIP": asnHeader,
        "SINV.SUPPLIER_DELIVERY.DETAIL.LOGISTICS" : asnHeader,
        "SINV.SUPPLIER_DELIVERY.DETAIL.ADD_LOGISTICS" : asnHeader,
        "SINV.SUPPLIER_DELIVERY.DETAIL.BASIC": asnLineList
//      "SINV.DELIVERY_CREATION_DETAIL.HEADERSHIP": asnHeader,
//      "SINV.DELIVERY_CREATION_DETAIL.LOGISTICS": asnHeader
    },
    throwOnException: false//如为false,则校验信息返回到result中
});

```

***

### 获取个性化字段

**描述**

* 该逻辑与Java中完全一致，只是代理

**名称**

* getAllFieldsAndTranslateFieldName

**入参**

| 参数名         | 必输  | 类型     | 默认值 | 说明                     |
|-------------|-----| ------ | --- |------------------------|
| unitCode | yes | string | 空   | 编码 |

**使用示例**

```javascript
const customize = require("@M/v1/customize");
const result  = customize.getAllFieldsReplaceFieldName({unitCode:"SSRC.INQUIRY_HALL.LIST"});
return { "result": result}

```
