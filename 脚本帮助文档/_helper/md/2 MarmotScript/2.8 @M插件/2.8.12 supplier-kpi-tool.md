# supplier-kpi-tool 供应商KPI工具
> summary: 供应商KPI计算工具，支持根据考评指标和参数计算供应商绩效得分
> 引用路径: @M/v1/supplier-kpi-tool
用于供应商KPI计算

**引入**

```javascript
let tool = require("@M/v1/supplier-kpi-tool");
```

***

### 计算供应商KPI

**描述**

*   计算供应商KPI

**名称**

*   queryFlmConfigScore

**入参**

| 参数名         | 必输  | 类型     | 默认值 | 说明        |
|-------------|-----| ------ | --- |-----------|
| evalTplIndFmlId      | yes | Long | 空   | 考评指标id    |
| paramField      | yes | String | 空   | 考评参数编码
| paramValue      | yes | String | 空   | 考评参数值    |

**使用示例**

```javascript
let tool = require("@M/v1/supplier-kpi-tool");
const result = tool.queryFlmConfigScore({
    "evalTplIndFmlId":"2768",
    "paramField":"code1",
    "paramValue":"AAA"
    });
```
