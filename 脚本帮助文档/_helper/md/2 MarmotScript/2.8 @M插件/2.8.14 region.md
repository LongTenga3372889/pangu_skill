# region
> summary: 地区信息查询工具，支持按ID或条件查询国家地区数据
> 引用路径: @M/v1/region
地区信息查询

**引入**
```javascript
let region = require("@M/v1/region");
```
***
### selectByRegionId
根据ID查询

| **参数名**     | **必输** | **类型** | **默认值** | **说明**                     |
| --------------- | ------ | ------ | ------- | -------------------------- |
| regionId | 是      | string | 空       | 主键|

```javascript
region.selectByRegionId({regionId:145190})
```
***

### query
多条件查询

| **参数名**         | **必输** | **类型** | **默认值** | **说明**                     |
| --------------- | ------ | ------ | ------- | -------------------------- |
| countryId   | 至少有一项不为空      | string | 空       | 国家id |
| regionCode   | 至少有一项不为空      | string | 空       | 地区编码 |
| regionName   | 至少有一项不为空      | string | 空       | 地区名称 |

```javascript
region.query({countryId:1,regionCode:"JW01",regionName:"境外地区"})
```
