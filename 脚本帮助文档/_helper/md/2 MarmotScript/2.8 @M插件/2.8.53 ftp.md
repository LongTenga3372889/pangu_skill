# ftp 文件传输
> summary: FTP/SFTP文件传输工具，支持上传下载删除及目录操作
> 引用路径: @M/v1/ftp

**引入**

```javascript
let ftp = require("@M/v1/ftp");
```

## uploadFile
上传文件到FTP服务器

| **参数名**     | **必输** | **类型** | **默认值** | **说明**                     |
| --------------- | ------ | ------ | ------- | -------------------------- |
| ftpMode | 是      | string | 空       | FTP模式（如：SFTP）|
| encryptionMode | 是      | string | 空       | 加密模式 |
| host | 是      | string | 空       | FTP主机地址|
| port | 是      | string | 空       | 端口号|
| username | 是      | string | 空       | 用户名|
| password | 是      | string | 空       | 密码|
| homePath | 否      | string | ./       | 主目录路径|
| fileName | 是      | string | 空       | 文件名|
| directory | 是      | string | 空       | 目标目录|
| buffer | 是      | array | 空       | 文件字节数组|

#### 使用示例

```javascript
let result = ftp.uploadFile({
    ftpMode: "SFTP",
    encryptionMode: "AES",
    host: "ftp.example.com",
    port: "22",
    username: "admin",
    password: "123456",
    homePath: "./",
    fileName: "test.txt",
    directory: "/uploads",
    buffer: new Uint8Array([72, 101, 108, 108, 111])
});
STD.Logger.info("uploadFile: {}", result);
```

| username | 是      | string | 空       | 用户名|
| password | 是      | string | 空       | 密码|
| homePath | 否      | string | ./       | 主目录路径|
| fileName | 是      | string | 空       | 文件名|
| directory | 是      | string | 空       | 文件所在目录|

#### 使用示例

```javascript
let buffer = ftp.downloadFile({
    ftpMode: "SFTP",

    fileName: "test.txt",

});

```

```json

```

## deleteDir

| --------------- | ------ | ------ | ------- | -------------------------- |
| ftpMode | 是      | string | 空       | FTP模式（如：SFTP）|
