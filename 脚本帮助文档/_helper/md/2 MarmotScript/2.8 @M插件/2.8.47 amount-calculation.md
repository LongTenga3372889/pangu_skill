## 含税单价转不含税单价及金额（getExcludingTaxUnitPriceAndAmount）

**描述**

*   根据含税单价、税率、数量、批量单价、币种计算不含税单价和金额

**名称**

*   getExcludingTaxUnitPriceAndAmount

**入参**

| **参数名**              | **必输** | **类型**   | **默认值** | **说明**     |
| ------------------- | ------ | -------- | ------- | ---------- |
| taxIncludedUnitPrice | 是      | number  | 空       | 含税单价      |
| taxRate             | 是      | number  | 空       | 税率        |
| quantity            | 是      | number  | 空       | 数量        |
| unitPriceBatch      | 否      | number  | 空       | 批量单价      |
| currencyCode        | 否      | string  | 空       | 币种编码      |

#### 使用示例

```javascript
function process(input) {
    let amountCalc = require("@M/v1/amount-calculation");
    
    let result = amountCalc.getExcludingTaxUnitPriceAndAmount({
        taxIncludedUnitPrice: 113,
        taxRate: 0.13,
        quantity: 100,
        unitPriceBatch: 100,
        currencyCode: "CNY"
    });
    
    STD.Logger.info("result: {}", result);
    return { result: result };
}
```

**返回结果示例**

```json
{
    "excludingTaxUnitPrice": 100,
    "taxRate": 0.13,
    "taxAmount": 1300,
    "quantity": 100,
    "totalExcludingTaxAmount": 10000,
    "totalTaxAmount": 1300,
    "currencyCode": "CNY"
}
```

## 不含税金额批量计算（getExcludingAmountCalculationResult）

**描述**

*   批量计算不含税金额，支持多组数据同时计算

**名称**

*   getExcludingAmountCalculationResult

**入参**

| **参数名**                   | **必输** | **类型**  | **默认值** | **说明**   |
| ------------------------ | ------ | ------- | ------- | -------- |
| amountCalculationParamDTOS | 是      | array  | 空       | 金额计算参数数组 |

#### 使用示例

```javascript
function process(input) {
    let amountCalc = require("@M/v1/amount-calculation");
    
    let params = [
        {
            taxIncludedUnitPrice: 113,
            taxRate: 0.13,
            quantity: 100,
            unitPriceBatch: 100
        },
        {
            taxIncludedUnitPrice: 226,
            taxRate: 0.13,
            quantity: 50,
            unitPriceBatch: 200
        }
    ];
    
    let result = amountCalc.getExcludingAmountCalculationResult(params);
    STD.Logger.info("result: {}", result);
    return { result: result };
}
```

**返回结果示例**

```json
[
    {
        "excludingTaxUnitPrice": 100,
        "taxRate": 0.13,
        "taxAmount": 1300,
        "quantity": 100,
        "totalExcludingTaxAmount": 10000,
        "totalTaxAmount": 1300
    },
    {
        "excludingTaxUnitPrice": 200,
        "taxRate": 0.13,
        "taxAmount": 1300,
        "quantity": 50,
        "totalExcludingTaxAmount": 10000,
        "totalTaxAmount": 1300
    }
]
```
