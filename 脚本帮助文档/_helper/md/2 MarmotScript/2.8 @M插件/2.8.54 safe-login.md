# safe-login 安全登录
> summary: RSA加密安全登录URL生成工具，用于SSO单点登录场景
> 引用路径: @M/v1/safe-login

**引入**

```javascript
let safeLogin = require("@M/v1/safe-login");
```

## generateSecurityLoginUrl
生成RSA加密的安全登录URL

**描述**

* 使用RSA私钥加密用户名和时间戳，生成安全的登录URL参数
* 私钥从`srm_advanced_options`表的`oauth_ctrl_login_one_step_private_key`配置项读取
* 用于单点登录场景，避免用户名明文传输

**名称**

* generateSecurityLoginUrl

**入参**

| **参数名**     | **必输** | **类型** | **默认值** | **说明**                     |
| --------------- | ------ | ------ | ------- | -------------------------- |
| username | 是      | string | 空       | 用户名|
| validTime | 否      | number | 空       | 有效时长（毫秒）|

#### 使用示例

```javascript
let encryptedUrl = safeLogin.generateSecurityLoginUrl({
    username: "admin",
    validTime: 60000
});
STD.Logger.info("safe login url: {}", encryptedUrl);
// 返回编码后的加密参数字符串，可作为登录URL的参数使用
```

**返回结果示例**

```json
// 返回经Base64编码并URL转义后的加密参数字符串
"JkHbG8xMjM0NTY3ODkwQWJjZGVmZ2hpamtsbW5vcHFyc3R1dnd4eXo%3D"
```

#### 注意事项

* 该方法依赖RSA私钥配置，若`srm_advanced_options`表中未配置`oauth_ctrl_login_one_step_private_key`，则使用内置默认私钥
* `validTime`参数可选，用于设置链接的有效期
* 返回值已经过URL编码，可直接拼接至登录URL参数中
