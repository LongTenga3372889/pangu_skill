# workflow
> summary: 工作流启动客户端，支持启动工作流、查询审批记录和业务对象树形结构
> 引用路径: @M/v1/workflow
工作流启动客户端
（如果你关心SAGA的话，本启动会启动SAGA事务）

**引入**

```javascript
const workFlow = require("@M/v1/workflow");
```

***

## 1. 启动工作流

```javascript
//工作流启动参数
let processStartDTO = {
    documentCode: "OFFICE_SUPPLIES",//单据编码，必填
    categoryCode: "XIAOXIN-TEST",//分类编码，必填
    businessKey: "TETS111",//业务主键，必填
    specifyUserId: 34428,//发送人id，非必填
    primaryKeyValue: 825867,//是用于支持模型，非必填
    variables: [
            //变量，非必填(需要个空数组)
            {name: "quantity",value: "1",type: "long"},
            {name: "unitPrice",value: "2",type: "double"},
            {name: "productName",value: "TEST",type: "string"}
        ]
    };
//执行成功后，返回流程实例id
let processInstanceId = workFlow.start(processStartDTO)

```

## 2. 查询单据历史审批记录

**描述**

*   根据条件批量查询单据历史审批记录（默认会拼上当前脚本的租户id作为条件）， 存在是否供应商判断，若为供应商，直接返回空，
      因此脚本编辑器界面debug会查不到数据，请结合功能测试

**名称**

*   historyApproval

**入参**

| **参数名**   | **必输** | **类型** | **默认值** | **说明**                       |
| --------- | ------ | ------ |---------| ---------------------------- |
| businessKey    | 是      | string | 空       | 业务主键	                       |
| needMerge | 否      | boolean     | false   | 是否需要合并当前运行中流程的审批记录|
| needVariable	 | 否      | boolean     | false   | 是否需要返回当前流程下的流程变量(返回全部) |
| filterAuto | 否      | boolean     | false   | 是否过滤自动审批记录|
| lang | 否      | String     | 空       | 翻译审批意见所使用的语言，默认中文( zh_CN ) |


#### 使用示例
```javascript
  const workFlow = require("@M/v1/workflow");
  let result = workFlow.historyApproval({businessKey:"TIMEOUT_RECEIVED_10221"})
```


## 3. 批量查询单据历史审批记录

**描述**

*   根据条件批量查询单据历史审批记录（默认会拼上当前脚本的租户id作为条件），存在是否供应商判断，若为供应商，直接返回空，
    因此脚本编辑器界面debug会查不到数据，请结合功能测试

**名称**

*   batchListHistoryApproval

**入参**

| **参数名**   | **必输** | **类型**  | **默认值** | **说明**                     |
| --------- | ------ |---------|---------|----------------------------|
| businessKeyList    | 是      | array   | 空       | 业务主键列表	                    |
| needMerge | 否      | boolean | false   | 是否需要合并当前运行中流程的审批记录         |
| needVariable	 | 否      | boolean | false   | 是否需要返回当前流程下的流程变量(返回全部)     |
| filterAuto | 否      | boolean | false   | 是否过滤自动审批记录                 |
| lang | 否      | String  | 空       | 翻译审批意见所使用的语言，默认中文( zh_CN ) |


#### 使用示例

```javascript
    let businessKeyList = ['TIMEOUT_RECEIVED_10221']
    let result = workFlow.batchListHistoryApproval({businessKeyList: businessKeyList})
```

## 4. 查询组合业务对象的树形结构数据

**描述**

* 查询组合业务对象的树形结构数据

**名称**

* businessObjectTree

**入参**

| **参数名**   | **必输** | **类型** | **默认值** | **说明**                    |
| --------- | ------ |--------|---------|---------------------------|
| businessObjectId    | 是      | string | 空       | 组合业务对象id	                   |
| ignoreRelateFlag | 否      | boolean | false   | 是否忽略关联关系标识       |
| includeFieldFlag	 | 否      | boolean | false   | 是否带出字段标识     |
| nameOrCode | 否      | string | false   | 字段名称或编码查询条件                |
| withPhysicalInfoFlag | 否      | boolean | false   | 是否携带物理模型信息 |
| erModeFlag | 否      | boolean | true    | 是否是ER图模式 |

#### 使用示例

```javascript
  workFlow.businessObjectTree({businessObjectId: -621})
```
