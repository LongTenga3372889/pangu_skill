## 生成MyBatis示例SQL（generateMybatisSampleSql）

**描述**

*   将MyBatis XML格式的SQL转换为示例SQL，用于解析和调试

**名称**

*   generateMybatisSampleSql

**入参**

| **参数名**  | **必输** | **类型**  | **默认值** | **说明**    |
| ------- | ------ | ------- | ------- | --------- |
| xmlSql  | 是      | string | 空       | MyBatis XML SQL |

#### 使用示例

```javascript
function process(input) {
    let sqlTool = require("@M/v1/sql-tool");
    
    let xmlSql = "<![CDATA[SELECT * FROM user WHERE id = #{id}]]>";
    let sampleSql = sqlTool.generateMybatisSampleSql(xmlSql);
    
    STD.Logger.info("sampleSql: {}", sampleSql);
    return { result: sampleSql };
}
```

**返回结果示例**

```text
SELECT * FROM user WHERE id = ?
```

## 获取SQL使用的表（getTableInUse）

**描述**

*   从MyBatis XML SQL或原生SQL中解析出所使用的表名列表

**名称**

*   getTableInUse

**入参**

| **参数名**      | **必输** | **类型**  | **默认值** | **说明**       |
| ----------- | ------ | ------- | ------- | ------------ |
| xmlSql      | 否      | string | 空       | MyBatis XML SQL |
| preparedSql | 否      | string | 空       | 原生SQL语句      |
| preparedArgs | 否      | object | 空       | 预编译SQL参数     |

#### 使用示例

```javascript
function process(input) {
    let sqlTool = require("@M/v1/sql-tool");
    
    // 使用XML SQL
    let xmlSql = "<![CDATA[SELECT * FROM user WHERE id = #{id}]]>";
    let tables = sqlTool.getTableInUse({ xmlSql: xmlSql });
    
    // 或使用预编译SQL
    // let tables = sqlTool.getTableInUse({ 
    //     preparedSql: "SELECT * FROM user WHERE id = ?",
    //     preparedArgs: { "1": "123" }
    // });
    
    STD.Logger.info("tables: {}", tables);
    return { result: tables };
}
```

**返回结果示例**

```json
["user"]
```

## 获取SQL完整信息（getSqlInfo）

**描述**

*   从SQL中解析出完整的元信息，包括使用的表、WHERE条件、分页标记、表别名映射等

**名称**

*   getSqlInfo

**入参**

| **参数名**      | **必输** | **类型**  | **默认值** | **说明**       |
| ----------- | ------ | ------- | ------- | ------------ |
| xmlSql      | 否      | string | 空       | MyBatis XML SQL |
| preparedSql | 否      | string | 空       | 原生SQL语句      |
| preparedArgs | 否      | object | 空       | 预编译SQL参数     |

#### 使用示例

```javascript
function process(input) {
    let sqlTool = require("@M/v1/sql-tool");
    
    let xmlSql = `<![CDATA[
        SELECT u.*, o.name as order_name 
        FROM user u 
        LEFT JOIN orders o ON u.id = o.user_id 
        WHERE u.id > 100 AND u.status = 'active'
        LIMIT 10
    ]]>`;
    
    let sqlInfo = sqlTool.getSqlInfo({ xmlSql: xmlSql });
    
    STD.Logger.info("sqlInfo: {}", sqlInfo);
    return { result: sqlInfo };
}
```

**返回结果示例**

```json
{
    "tableFound": ["user", "orders"],
    "limitMarked": true,
    "whereFound": {
        "u.id": "100",
        "u.status": "active"
    },
    "tableDetailsFound": {
        "u": "user",
        "o": "orders"
    }
}
```

## 判断表是否有租户ID（hasTenantId）

**描述**

*   判断指定表是否包含租户ID字段

**名称**

*   hasTenantId

**入参**

| **参数名**   | **必输** | **类型**  | **默认值** | **说明**  |
| -------- | ------ | ------- | ------- | ------- |
| tableName | 是      | string | 空       | 表名     |

#### 使用示例

```javascript
function process(input) {
    let sqlTool = require("@M/v1/sql-tool");
    
    let hasTenant = sqlTool.hasTenantId("hpfm_user");
    
    STD.Logger.info("hasTenant: {}", hasTenant);
    return { result: hasTenant };
}
```

**返回结果示例**

```json
true
```
