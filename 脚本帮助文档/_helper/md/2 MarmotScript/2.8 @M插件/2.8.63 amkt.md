# amkt 签约管理
> summary: 签约管理工具，提供电子签约任务的创建、签署链接生成、附件下载等能力
> 引用路径: @M/v1/amkt

**引入**
```javascript
let amkt = require("@M/v1/amkt");
```

***

## createSignTask

创建签约任务

#### 入参

| **参数名** | **必输** | **类型** | **默认值** | **说明** |
| --------- | ------ | ------ | ------- | ------ |
| organizationId | 是 | string | 空 | 组织ID |
| body | 是 | object | 空 | 签约任务配置 |

#### 使用示例

```javascript
function process(input) {
    let amkt = require("@M/v1/amkt");
    let result = amkt.createSignTask("ORG_001", {
        signType: "CONTRACT",
        fileId: "FILE_123",
        signers: [{ userId: "USER_001", role: "发起方" }]
    });
    return { result: result };
}
```

## generateSignUrl

生成签署链接

#### 入参

| **参数名** | **必输** | **类型** | **默认值** | **说明** |
| --------- | ------ | ------ | ------- | ------ |
| organizationId | 是 | string | 空 | 组织ID |
| body | 是 | object | 空 | 签署任务配置 |

#### 使用示例

```javascript
function process(input) {
    let amkt = require("@M/v1/amkt");
    let result = amkt.generateSignUrl("ORG_001", {
        taskId: "TASK_123",
        userId: "USER_001",
        returnUrl: "https://example.com/callback"
    });
    return { result: result };
}
```
