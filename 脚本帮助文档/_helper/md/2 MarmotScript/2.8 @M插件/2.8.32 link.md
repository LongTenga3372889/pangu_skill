# link 链接操作
> summary: 链接操作工具，提供短链接生成能力，用于短信链接等场景
> 引用路径: @M/v1/link
链接进行的一些操作

**引入**

```javascript
let link = require("@M/v1/link");
```

***
## 创建短链接
**描述**

*   将链接转成短链接，典型场景：短信链接

**名称**

*   createShortLink

**入参**

| 参数名 | 必输  | 类型     | 说明   |
|-----|-----| ------ |------|
| url | 是 | string | 原始地址 |


**使用示例**
```javascript
let shortLink = link.createShortLink({url:"https://zhenyun.dev.isrm.going-link.com/app/pub/marmot-help-manual"})
```
**成功返回示例**
```json
{
  "status" : "success",
  "shortUrl" : "https://short.going-link.com/bcc0d99069297bd8f6b707038cd248f5"
}
```
**失败返回示例**
```json
{
  "status" : "fail", 
  "message" : "Short URL 072fdb61ddcb8824ca7362e14d829cc0 already exists in database or is reserved"
}
```
