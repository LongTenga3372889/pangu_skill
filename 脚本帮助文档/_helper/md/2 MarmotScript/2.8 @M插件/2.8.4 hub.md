# hub
> summary: PDF生成工具，通过模板编码对RTF文件进行填充生成PDF文档
> 引用路径: @M/v1/hub

#### generateTemplatedPDF({templateCode,param})——通过模板编码对RTF填充

**导入：**

```javascript
let hubHelper = require("@M/v1/hub");
```

**入参：**

| 参数名          | 必输 | 类型     | 默认值 | 说明       |
| ------------ | --- | ------ | --- | -------- |
| templateCode | 是  | string | 空   | 模板填充编码   |
| param        | 是  | object | 空   | 模板填充所需参数 |

**示例：**

```javascript
let bytes = hubHelper.generateTemplatedPDF({templateCode:"xxxxx",param:{}});

```
