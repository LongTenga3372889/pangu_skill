# console 控制台工具
> summary: 控制台工具，提供log/warn/error日志输出方法封装STD.Logger
> 引用路径: @M/v1/console

**引入**
```javascript
let console = require("@M/v1/console");
```

## 目录

* [log](#log)
* [warn](#warn)
* [error](#error)

***

### log
输出info级别日志

#### 描述

*   将内容以info级别输出到日志

#### 使用示例

```javascript
function process(input) {
    let console = require("@M/v1/console");
    console.log("这是一条普通日志: {}", "Hello World");
}
```

***

### warn
输出warn级别日志

#### 描述

*   将内容以warn级别输出到日志

#### 使用示例

```javascript
function process(input) {
    let console = require("@M/v1/console");
    console.warn("这是一条警告日志: {}", "Warning Message");
}
```

***

### error

#### 描述

*   将内容以error级别输出到日志

