# serial-generator
> summary: 序列化编码生成器，支持UUID、有序序列号和规则编码生成
> 引用路径: @M/v1/serial-generator
序列化编码生成器

**引入**
```javascript
let serialGenerator = require("@M/v1/serial-generator");
```
## 目录

* [uuid生成-randomUUID](#randomUUID)
* [有序序列号生成-serialAZ09](#serialAZ09)
* [规则编码生成-generateCode](#generateCode)

### randomUUID
uuid生成

```javascript
serialGenerator.randomUUID();
```

### serialAZ09
从1开始生成序列号，每执行一个，同key下序列号加一。

| **参数名**         | **必输** | **类型** | **默认值** | **说明**                     |
| --------------- | ------ | ------ | ------- | -------------------------- |
| key   | 是     | string | 空       | 序列key |
| maxLength   | 是      | number| 空       | 序列号最大长度 |

```javascript
serialGenerator.serialAZ09({key:"abc123",maxLength: 12});
//输出 => 000000000001
```

### generateCode
按照编码规则生成对应编码。

> ⚠️ **与 STD.CodeRuleHelper.generateCode 的区别**
>
> | 维度 | serialGenerator.generateCode | STD.CodeRuleHelper.generateCode |
> |------|------------------------------|----------------------------------|
> | 调用方式 | **单个解构对象** `({ruleCode, variableMap, levelCode, levelValue})` | **两个位置参数** `("ruleCode", {variableMap})` |
> | 编码维度 | **TENANT（租户级）** 先按脚本租户查，查不到降级到 PLATFORM | **PLATFORM（平台级）** 全局连续，不可降级 |
> | 序列号 | 租户内连续 | 全局连续 |
>
> 传参错误示例：`serialGenerator.generateCode("SMAL.ADDRESS", {})` ❌（字符串不能解构，ruleCode=undefined）
> 正确示例：`serialGenerator.generateCode({ruleCode:"SMAL.ADDRESS", variableMap:{}})` ✅

| **参数名**         | **必输** | **类型** | **默认值** | **说明**                     |
| --------------- | ------ | ------ | ------- | -------------------------- |
| ruleCode   | 是     | string | 空       | 编码规则 |
| variableMap  | 是      | object| 空       | 参数map |
| levelCode   | 否      | string| `"GLOBAL"` | 应用层级 |
| levelValue   | 否      | string| `"GLOBAL"` | 应用层级值 |

```javascript
serialGenerator.generateCode({ruleCode:"TEST_STD",variableMap:{}});
serialGenerator.generateCode({ruleCode:"TEST_STD",variableMap:{}});
//输出 => test1,test2
serialGenerator.generateCode({
    ruleCode:"TEST_STD",
    variableMap:{"customSeq":777}, //可省略
    levelCode:"CUSTOM",//可省略，默认"GLOBAL"
    levelValue:"TEST" //可省略，默认"GLOBAL"
}
);
//输出 => 77701
```
