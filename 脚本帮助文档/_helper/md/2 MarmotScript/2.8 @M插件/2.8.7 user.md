# user
> summary: 用户信息查询工具，支持多条件查询、按ID/登录名/手机号/邮箱/员工编号/角色等维度查询
> 引用路径: @M/v1/user

>用于查询用户相关信息

> 只能查询当前脚本租户下的user信息，如果需要查询供应商用户需要写queryblock

### 多条件查询

**描述**

*   通过多种条件查询对应用户信息，查询唯一条件返回对象，查询不唯一条件返回数组。

**名称**

*   query

**入参**

| 参数名       | 必输        | 类型     | 默认值 | 说明        |
| --------- | --------- | ------ | --- | --------- |
| id        | 至少一个参数不为空 | string | 空   | user数据库id |
| loginName | 至少一个参数不为空 | string | 空   | 登录名       |
| realName  | 至少一个参数不为空 | string | 空   | 用户实名      |
| phone     | 至少一个参数不为空 | string | 空   | 用户绑定的手机号  |
| email     | 至少一个参数不为空 | string | 空   | 用户绑定的邮箱账号 |

**使用示例**

```javascript
let user = require("@M/v1/user");
let result = user.query({id:91475});
```

### 获取外部用户ID

**描述**

* 获取内部用户对应的外部用户id

**名称**

* getEsUserId

**入参**

| 参数名       | 必输        | 类型     | 默认值 | 说明        |
| --------- | --------- | ------ | --- | --------- |
| userIdList        | 是 | array | 空   | 内部用户id数组 |
| externalSystemCode        | 是 | string | 空   | 外部系统编码 |

**使用示例**

```javascript
let user = require("@M/v1/user");
let result = user.getEsUserId({
    userIdList:[123,456],
    externalSystemCode:"ABCDE"
});
```

**返回示例**

```javascript
result = [ {
    "user_id" : "123",
    "es_user_id" : "321"
}, {
    "user_id" : "456",
    "es_user_id" : "654"
} ]
```
