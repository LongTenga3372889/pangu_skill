# exception 异常定义
> summary: 脚本异常定义模块，提供BusinessException、SimpleException和Error三种异常类型
> 引用路径: @M/v1/exception

## 目录

* [BusinessException](#businessexception)
* [SimpleException](#simpleexception)
* [Error](#error)

## 引入

```javascript
const {BusinessException, SimpleException, Error} = require("@M/v1/exception");
```

***

## BusinessException

**描述**

* 业务异常，用于在业务逻辑中抛出需要特殊处理的异常
* 支持传入消息和错误码

**构造函数入参**

| **参数名**     | **必输** | **类型** | **默认值** | **说明** |
| ----------- | ------ | ------ | ------- | ------ |
| obj        | 是     | object/string | 空   | 消息对象或字符串 |
| code       | 否     | string | 空       | 错误码  |

**obj为对象时的可用属性**

| **参数名**     | **必输** | **类型** | **默认值** | **说明** |
| ----------- | ------ | ------ | ------- | ------ |
| message     | 是     | string | 空       | 错误消息 |
| args        | 否     | array  | 空       | 消息参数 |

#### 使用示例

```javascript
const {BusinessException} = require("@M/v1/exception");

// 方式1：传入字符串消息
throw new BusinessException("操作失败");

// 方式2：传入对象
throw new BusinessException({
    message: "用户不存在",
    args: ["userId", "12345"]
});

// 方式3：带错误码
throw new BusinessException({
    message: "库存不足"
}, "INVENTORY_SHORTAGE");
```

**异常属性**

| **属性名**     | **类型** | **说明** |
| ----------- | ------ | ------ |
| message     | string | 错误消息 |
| args        | array  | 消息参数 |
| code        | string | 错误码，默认为MARMOT_SCRIPT_BUSINESS_EXCEPTION |
| _marmot_script_business_exception_flag | boolean | 标识为业务异常 |

***

## SimpleException

**描述**

* 简单异常，用于通用错误场景
* 支持格式化参数

**构造函数入参**

| **参数名**     | **必输** | **类型** | **默认值** | **说明** |
| ----------- | ------ | ------ | ------- | ------ |
| message     | 是     | string | 空       | 错误消息 |
| args        | 否     | array  | 空       | 消息参数 |

#### 使用示例

```javascript
const {SimpleException} = require("@M/v1/exception");

// 简单异常
throw new SimpleException("数据验证失败");

// 带参数的异常
throw new SimpleException("第{}行第{}列数据格式错误", [1, 3]);

// 在feign-client2中被自动使用
// 当服务返回{failed: true, message: "错误信息"}时抛出此异常
```

**异常属性**

| **属性名**     | **类型** | **说明** |
| ----------- | ------ | ------ |
| message     | string | 错误消息 |
| args        | array  | 消息参数 |
| _marmot_script_simple_exception_flag | boolean | 标识为简单异常 |
| _marmot_sandbox_exception | boolean | 标识为沙箱异常 |

**toJSON/toString**

* 返回`this.message`，便于日志记录和序列化

***

## Error

**描述**

* 错误类型，是SimpleException的别名
* 用于替代原生Error对象

**使用示例**

```javascript
const {Error} = require("@M/v1/exception");

// 等同于new SimpleException("错误信息")
throw new Error("这是一个错误");
```

***

## 异常使用场景

| 异常类型       | 使用场景                           |
| ------------ | ------------------------------- |
| BusinessException | 业务校验失败、业务规则违反、需要明确错误码的场景 |
| SimpleException   | 通用错误、需要格式化消息参数、Feign调用失败 |
| Error             | 替代原生Error、需要统一异常处理的场景     |

## 注意事项

1. BusinessException必须传入消息，否则抛出"Business Exception must has a message"
2. SimpleException支持JSON序列化，toJSON方法返回message字符串
3. 所有异常都会添加沙箱标识`_marmot_sandbox_exception: true`
4. 在脚本中使用try-catch可以捕获这些异常进行处理
