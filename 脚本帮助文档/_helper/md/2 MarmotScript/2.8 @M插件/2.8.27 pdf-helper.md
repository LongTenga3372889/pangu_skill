# pdf-helper PDF助手
> summary: PDF处理工具，支持水印/合并/格式转换/页数获取
> 引用路径: @M/v1/pdf-helper

**引入：**

```javascript
let pdfHelper = require("@M/v1/pdf-helper");
```
***
### watermarkWithConfigByUrl
给pdf设置水印

| **参数名**     | **必输** | **类型** | **默认值** | **说明**                     |
| --------------- | ------ | ------ | ------- | -------------------------- |
| url | 是      | string | 空       | pdf地址|
| bucketName | 是      | string | 空       | pdf的bucketName|
| waterConfig | 是      | string| 空       | 水印参数|
| params | 否      | string| 空       | 自定义参数|

```javascript
let url =
    "https://isrm-dev-public-bucket.obs.cn-east-2.myhuaweicloud.com:443/editor/0/68b929faded44ea4b116e683f067dd46@test1.pdf";
let bucketName = "public-bucket";
let imageUrl = "https://isrm-dev-public-bucket.obs.cn-east-2.myhuaweicloud.com:443/editor/0/75de1e89cfa340d28406ef7a82d41281@薯条.png";
let fontUrl = "https://isrm-dev-private-bucket.obs.cn-east-2.myhuaweicloud.com:443/sodr-order/8079/4264d30ecb2e4ffd899c2aecb505c631@微软雅黑字体.ttf";
let types = ["TEXT","IMAGE","TILE_TEXT","TILE_IMAGE"];  //水印类型，TILE代表铺满
/**文字水印配置**/
let textConfig = {
    watermarkType: types[0], //水印类型
    fillOpacity: 0.8, //填充字体不透明度
    color: "#D2691E",	//填充字体颜色
    fontSize: 25,	//字体大小
    xAxis: 100,		//水印横向坐标
    yAxis: 200,		//水印纵向坐标
    align: 1,
    rotation: 25,	//水印倾斜角度
    detail: "abc123",		//详细信息,文本类型水印代表文本内容，图片类型水印代表图片地址
    contextBucket:"",	//图片类型水印bucketName
    fontUrl:fontUrl,
    fontBucketName:"private-bucket"
};
/**图片水印配置**/
let imageConfig = {
    watermarkType: types[1], //水印类型
    fillOpacity: 0.8, //填充字体不透明度
    xAxis: 100,		//水印横向坐标
    yAxis: 200,		//水印纵向坐标
    rotation: 25,	//水印倾斜角度
    detail: imageUrl,		//详细信息,文本类型水印代表文本内容，图片类型水印代表图片地址
    contextBucket:bucketName,	//图片类型水印bucketName
    weight:200,
    height:200
};
let bytes = pdfHelper.watermarkWithConfigByUrl({
    url: url,
    bucketName: bucketName,
    waterConfig: textConfig,
    params: {}
});
```

### mergePdf
合并为一个pdf（支持pdf和doc类型）

| **参数名**     | **必输** | **类型** | **默认值** | **说明**                     |
| --------------- | ------ | ------ | ------- | -------------------------- |
| fileList | 是      | string | 空       | 合并pdf的url和bucketName数组|

```javascript
let file = {
    fileUrl:"https://isrm-dev-private-bucket.obs.cn-east-2.myhuaweicloud.com:443/hwfp01/30/0f2f856d4fb0417fa06711e5f4c8151f@docx.docx",
    bucketName:"private-bucket"
}
let bytes = pdfHelper.mergePdf({
    fileList: [
        file,file
    ]
});
```

### wordToPdf
word转为pdf格式

| **参数名**     | **必输** | **类型** | **默认值** | **说明**                     |
| --------------- | ------ | ------ | ------- | -------------------------- |
| fileUrl | 是      | string | 空       | word文件地址|
| bucketName | 否      | string | private-bucket       | 桶|

```javascript
let url = "https://isrm-dev-private-bucket.obs.cn-east-2.myhuaweicloud.com:443/hwfp01/30/0f2f856d4fb0417fa06711e5f4c8151f@docx.docx";
let bytes = pdfHelper.wordToPdf({fileUrl:url});
```

### getNumberOfPage
获取pdf页数

| **参数名**     | **必输** | **类型** | **默认值**        | **说明**  |
| --------------- | ------ | ------ |----------------|---------|
| fileUrl | 是      | string | 空              | pdf文件地址 |
| bucketName | 否      | string | private-bucket | 桶       |
| storageCode | 否      | string | 空              | 存储配置编码  |

```javascript
let url = "XXXXXX";
let num = pdfHelper.getNumberOfPage({fileUrl: url});
```
