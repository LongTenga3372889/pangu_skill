# logger
> summary: 日志生成器，支持debug/info/warn/error四级日志输出
> 引用路径: @M/v1/logger
日志生成器

**引入**
```javascript
let logger = require("@M/v1/logger");
```
## 目录

* [DEBUG](#DEBUG)
* [INFO](#INFO)
* [ERROR](#ERROR)
* [WARN](#WARN)

***
### DEBUG
生成debug级日志

| **参数名**         | **必输** | **类型** | **默认值** | **说明**      |
| --------------- | ------ | ------ | ------- | -------------------------- |
| msg   | 是     | string | 空       | 常量编码 |
| strs   | 是     | array | 空       | 常量编码 |

```javascript
logger.debug({msg:"aaa{}, lll{}", strs:["konomama","-=-129h"]})
```
