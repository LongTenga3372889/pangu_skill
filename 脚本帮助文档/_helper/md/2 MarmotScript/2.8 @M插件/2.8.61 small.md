# small 商城小工具
> summary: 商城小工具集，提供消息发送、字符串操作、ES数据同步等能力
> 引用路径: @M/v1/small

**引入**
```javascript
let small = require("@M/v1/small");
```

***

## sendMsg

发消息

#### 入参

| **参数名** | **必输** | **类型** | **默认值** | **说明** |
| --------- | ------ | ------ | ------- | ------ |
| messageCode | 是 | string | 空 | 消息编码 |
| messageTag | 是 | string | 空 | 消息标签 |
| buKey | 是 | string | 空 | 业务Key |
| data | 是 | object | 空 | 消息数据 |

#### 使用示例

```javascript
function process(input) {
    let small = require("@M/v1/small");
    small.sendMsg({
        messageCode: "ORDER_CREATE",
        messageTag: "TAG_ORDER",
        buKey: "ORDER_BU",
        data: { orderId: "12345", amount: 100 }
    });
}
```

## curd-stringutils 子模块

字符串增删工具

**引入**
```javascript
let curdStringutils = require("@M/v1/small/curd-stringutils");
```

### insertString

增加字符串

#### 入参

| **参数名** | **必输** | **类型** | **默认值** | **说明** |
| --------- | ------ | ------ | ------- | ------ |
| all | 是 | string | 空 | 原字符串 |
| value | 是 | string | 空 | 要插入的字符串 |

#### 使用示例

```javascript
function process(input) {
    let curdStringutils = require("@M/v1/small/curd-stringutils");
    let result = curdStringutils.insertString({ all: "hello", value: " world" });
    // 结果: "hello world"
}
```

### deleteString

| --------- | ------ | ------ | ------- | ------ |
| all | 是 | string | 空 | 原字符串 |
| value | 是 | string | 空 | 要删除的字符串 |

#### 使用示例

```javascript
function process(input) {
    let curdStringutils = require("@M/v1/small/curd-stringutils");
```

## es-data-sync-client 子模块

ES数据同步客户端

**引入**
```javascript
let esDataSyncClient = require("@M/v1/small/es-data-sync-client");
```

### sendNoException

不抛出异常的发送事件到MQ（支持集合类型）

#### 入参

| **参数名** | **必输** | **类型** | **默认值** | **说明** |
| --------- | ------ | ------ | ------- | ------ |
| inputSourceCode | 是 | string | 空 | 输入源编码 |
| data | 是 | object/array | 空 | 修改数据 |

#### 使用示例

```javascript
function process(input) {
    let esDataSyncClient = require("@M/v1/small/es-data-sync-client");
    esDataSyncClient.sendNoException({
        inputSourceCode: "ORDER_SYNC",
        data: [{ id: 1, status: "COMPLETED" }]
    });
}
```

### send

发送事件到MQ（支持集合类型）

#### 入参

| **参数名** | **必输** | **类型** | **默认值** | **说明** |
| --------- | ------ | ------ | ------- | ------ |
| inputSourceCode | 是 | string | 空 | 输入源编码 |
| data | 是 | object/array | 空 | 修改数据 |
| sendOrderly | 否 | boolean | true | 是否有序发送 |
| transaction | 否 | boolean | true | 是否开启事务 |

#### 使用示例

```javascript
function process(input) {
    let esDataSyncClient = require("@M/v1/small/es-data-sync-client");
    esDataSyncClient.send({
        inputSourceCode: "ORDER_SYNC",
        data: { id: 1, status: "COMPLETED" },
        sendOrderly: true,
        transaction: true
    });
}
```
