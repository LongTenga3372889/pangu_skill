# query-block SQL查询
> summary: 预配置SQL查询块工具，支持列表/单条/分页查询
> 引用路径: @M/v1/query-block
sql查询工具
>>QueryBlock属于涉Database操作，单次操作超时时间为10秒，不可更改
> 

**引入**
```javascript
let queryblock = require("@M/v1/query-block");
```
## 目录

* [selectList](#selectList)
* [selectOne](#selectOne)
* [selectPage](#selectPage)

### 注意：
>使用该方法需要在MarmotScript控制台中的queryBlock配置项进行配置

> 查询数据务必使用tenantId进行条件筛选,建议从UserDetails取当前角色tenantId
如特殊情况取不到当前tenantId，则（#{executionTenantId},代表该脚本的归属租户id）

>查询数据务必谨慎的关联平台数据，能少查几个字段，就少查几个字段，不要从Java代码中大段大段复制

>务必确保单次查询性能，每次查询超时时间为10s，非常严格

>了性能更好，减少表join，尽可能为每个表都使用tenantId作为条件

>QueryBlock必须写明需求号

***

### selectList
查询数据列表

| **参数名**     | **必输** | **类型** | **默认值** | **说明**                     |
| --------------- | ------ | ------ | ------- | -------------------------- |
| code | 是      | string | 空       | queryBlock编码|
| param | 否      | object | {}       | 查询所需参数|

```javascript
queryblock.selectList({
    code:"SADA_ERROR_ASSOCIATOR_GET", 
    param:{userId:"496015"}
});
```
***

### selectPage
查询分页数据，若配置了自定义countSql，则会走自定义count，否则走默认count

| **参数名**     | **必输** | **类型** | **默认值** | **说明**                     |
| --------------- | ------ | ------ | ------- | -------------------------- |
| code | 是      | string | 空       | queryBlock编码|
| param | 否      | object | {}       | 查询所需参数|
| pageRequest | 是      | object | 空       | 分页参数|

```javascript
queryblock.selectPage({
    code:"SADA_ERROR_ASSOCIATOR_GET",
    param:{userId:"496015"},
    pageRequest:{page:0,size:10}
});
```
