# feign-client2 Feign客户端封装
> summary: 基于FeignClient的封装，提供带异常处理的HTTP请求方法，自动解析JSON响应
> 引用路径: @M/v1/feign-client2

## 目录

* [selectClient](#selectclient)
* [doGet](#doget)
* [doPost](#dopost)
* [doPut](#doput)
* [doDelete](#dodelete)

## 引入

```javascript
const feignClient2 = require("@M/v1/feign-client2");
```

## selectClient

**描述**

* 根据serverId选择Feign客户端实例，返回封装好的请求方法

**入参**

| **参数名**     | **必输** | **类型** | **默认值** | **说明** |
| ----------- | ------ | ------ | ------- | ------ |
| serverId   | 是     | string | 空       | 服务ID  |

#### 使用示例

```javascript
const feignClient2 = require("@M/v1/feign-client2");

// 选择服务客户端
let client = feignClient2.selectClient({serverId: "srm-service"});
```

***

## doGet

**描述**

* 发送GET请求，自动处理响应并转换JSON

**入参**

| **参数名**     | **必输** | **类型** | **默认值** | **说明** |
| ----------- | ------ | ------ | ------- | ------ |
| path        | 是     | string | 空       | 请求路径 |
| header      | 否     | object | 空       | 请求头  |

#### 使用示例

```javascript
const feignClient2 = require("@M/v1/feign-client2");

let client = feignClient2.selectClient({serverId: "srm-service"});

// 发送GET请求
let result = client.doGet({
    path: "/api/users/123",
    header: {
        "Content-Type": "application/json"
    }
});
```

**返回结果示例**

```json
{
    "id": 123,
    "name": "张三",
    "email": "zhangsan@example.com"
}
```

**异常处理**

* 若服务返回`{failed: true, message: "错误信息"}`，则抛出SimpleException

***

## doPost

**描述**

* 发送POST请求，自动处理响应并转换JSON

**入参**

| **参数名**     | **必输** | **类型** | **默认值** | **说明** |
| ----------- | ------ | ------ | ------- | ------ |
| path        | 是     | string | 空       | 请求路径 |
| body        | 否     | object | 空       | 请求体  |

#### 使用示例

```javascript
const feignClient2 = require("@M/v1/feign-client2");

let client = feignClient2.selectClient({serverId: "srm-service"});

// 发送POST请求创建数据
let result = client.doPost({
    path: "/api/users",
    body: {
        name: "张三",
        email: "zhangsan@example.com"
    }
});
```

**返回结果示例**

```json
{
    "id": 456,
    "name": "张三",
    "email": "zhangsan@example.com",
    "creationDate": "2024-01-01 10:00:00"
}
```

**异常处理**

* 若服务返回`{failed: true, message: "错误信息"}`，则抛出SimpleException

## 响应处理机制

1. 自动解析响应体为JSON对象
2. 若响应体是字符串且可解析为JSON，则自动转换
3. 若服务返回`{failed: true}`，自动抛出SimpleException
4. 返回null也视为成功

## 注意事项

1. 需要先调用`selectClient`选择服务，再调用具体的HTTP方法
2. 底层依赖@M/v1/feign-client模块
3. 所有方法均自动处理异常，调用方无需try-catch捕获业务异常
