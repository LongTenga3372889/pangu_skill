# email 邮箱
> summary: 邮箱操作工具，支持附件拉取/已读设置/邮件信息查询
> 引用路径: @M/v1/email
邮箱操作
连接邮箱进行的一些操作

**引入**

```javascript
let email = require("@M/v1/email");
```

***
### 拉取邮箱中所有附件
**描述**

*   拉取邮箱中所有未读消息的附件

**名称**

*   fetchUnreadEmailAttachments

**入参**

| 参数名       | 必输        | 类型     | 默认值 | 说明        |
| --------- | --------- | ------ | --- | --------- |
| protocol        | 否 | string | imaps   | 访问协议 |
| port | 否 | string | -1   | 目标邮箱端口       |
| host  | 是 | string | 无   | 邮箱host地址      |
| user     | 是 | string | 无   | 邮箱账户  |
| password     | 是 | string | 无   | 邮箱密码（或校验码） |
| readOnlyFlag     | 否 | string | 2   | 是否以只读方式读取附件，1为只读，2为读写（非只读时会将邮件变为已读） |

**使用示例**
```javascript
let r = email.fetchUnreadEmailAttachments({
    protocol:"imaps",
    host:"imap.163.com",
    user:"paca@163.com",
    password:"AKUSGHDFKAGSFJAS",
    port:110
});
```
**返回示例**
```json
[{
    "bytes":[1,2,3],  //byte字节流
    "fileName":"abc.png",  //文件名
    "emailNum":240   //邮件编号
}]
```

### 设置邮箱邮件为已读

**描述**

*   设置邮箱邮件为已读

**名称**

*   setMessageRead

**入参**

| 参数名       | 必输        | 类型     | 默认值 | 说明        |
| --------- | --------- | ------ | --- | --------- |
| protocol        | 否 | string | imaps   | 访问协议 |

### 读取所有邮件简单信息

**描述**

*   读取所有邮件简单信息

**名称**

*   fetchEmailInfoList

**入参**

| 参数名       | 必输        | 类型     | 默认值 | 说明        |
| --------- | --------- | ------ | --- | --------- |
| protocol        | 否 | string | imaps   | 访问协议 |
| port | 否 | string | -1   | 目标邮箱端口       |
| host  | 是 | string | 无   | 邮箱host地址      |
| user     | 是 | string | 无   | 邮箱账户  |
| password     | 是 | string | 无   | 邮箱密码（或校验码） |
| emailStatusFlag     | 是 | number | 3   | 根据邮件状态查询邮件(1：未读，2：已读，3：未读和已读) |
| startTime     | 否 | date | 无   | 邮件接收时间范围起始 |
| endTime     | 否 | date | 无   | 邮件接收时间范围结束 |
| title     | 否 | string | 无   | 邮箱标题 |
**使用示例**
```javascript
let r =email.fetchEmailInfoList({
    protocol:"imaps",
    host:"imap.163.com",
    user:"paca@163.com",
    password:"AKUSGHDFKAGSFJAS",
    port:110,
    emailStatusFlag:3,
    startTime:'2022-01-01 00:00:00',
    endTime:"2022-12-01 00:00:00",
    title:""
});
```
**返回示例**
```json
 [ {
  "emailNum" : "1",
  "title" : "测试消息",
  "readFlag" : "1",
  "attachmentFlag" : "0"
}, {
  "emailNum" : "2",
  "title" : "Test",
  "readFlag" : "1",
  "attachmentFlag" : "0"
}, {
  "emailNum" : "3",
  "title" : "testFile",
  "readFlag" : "0",
  "attachmentFlag" : "1"
} ]
```

### 根据邮件编号读取附件

**描述**

*   根据邮件编号读取附件

**名称**

*   fetchEmailAttachmentsByNum

**入参**

| 参数名       | 必输        | 类型     | 默认值 | 说明        |
| --------- | --------- | ------ | --- | --------- |
| protocol        | 否 | string | imaps   | 访问协议 |
| port | 否 | string | -1   | 目标邮箱端口       |
| host  | 是 | string | 无   | 邮箱host地址      |
| user     | 是 | string | 无   | 邮箱账户  |
| password     | 是 | string | 无   | 邮箱密码（或校验码） |
| readOnlyFlag     | 否 | string | 2   | 是否以只读方式读取附件，1为只读，2为读写（非只读时会将邮件变为已读） |
| messageNums     | 是 | array | 无   | 邮件编号 |
**使用示例**
```javascript
let r =email.fetchEmailAttachmentsByNum({
    protocol:"imaps",
    host:"imap.163.com",
    user:"paca@163.com",
    password:"AKUSGHDFKAGSFJAS",
    port:110,
    messageNums:[1,2,3]
});

```
**返回示例**
```json
[{
  "bytes":[1,2,3],  //byte字节流
  "fileName":"abc.png",  //文件名
  "emailNum":240   //邮件编号
}]
```
