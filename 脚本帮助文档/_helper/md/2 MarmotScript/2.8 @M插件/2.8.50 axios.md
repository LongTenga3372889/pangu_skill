# axios HTTP客户端
> summary: 仿Axios风格的HTTP客户端，支持get/post/put/delete请求及自定义header和响应类型
> 引用路径: @M/v1/axios

## 目录

* [get](#get)
* [post](#post)
* [put](#put)
* [delete](#delete)

## 引入

```javascript
const axios = require("@M/v1/axios");
```

## get

**描述**

* 发送GET请求，不带请求体

**入参**

| **参数名**     | **必输** | **类型** | **默认值** | **说明** |
| ----------- | ------ | ------ | ------- | ------ |
| url        | 是     | string | 空       | 请求地址 |
| options    | 否     | object | {}      | 配置项  |

**options配置项**

| **参数名**     | **必输** | **类型** | **默认值** | **说明** |
| ----------- | ------ | ------ | ------- | ------ |
| headers    | 否     | object | 空       | 请求头  |
| responseType | 否   | string | json     | 响应类型，如"json"、"arraybuffer" |

#### 使用示例

```javascript
const axios = require("@M/v1/axios");

// 简单GET请求
let result = axios.get("http://example.com/api/data");

// 带header的GET请求
let result = axios.get("http://example.com/api/data", {
    headers: {
        "Content-Type": "application/json",
        "Authorization": "Bearer token123"
    }
});

// 指定响应类型
let result = axios.get("http://example.com/api/file", {
    responseType: "arraybuffer"
});
```

**返回结果示例**

```json
{
    "data": "响应数据内容",
    "status": 200,
    "statusText": "OK",
    "responseHeaders": {
        "content-type": "application/json"
    }
}
```

## post

**描述**

* 发送POST请求，带请求体

**入参**

| **参数名**     | **必输** | **类型** | **默认值** | **说明** |
| ----------- | ------ | ------ | ------- | ------ |
| url        | 是     | string | 空       | 请求地址 |
| data       | 否     | object | 空       | 请求体数据 |
| options    | 否     | object | {}      | 配置项  |

**options配置项**

| **参数名**     | **必输** | **类型** | **默认值** | **说明** |
| ----------- | ------ | ------ | ------- | ------ |
| headers    | 否     | object | 空       | 请求头  |
| responseType | 否   | string | json     | 响应类型，如"json"、"arraybuffer" |

#### 使用示例

```javascript
const axios = require("@M/v1/axios");

// 简单POST请求
let result = axios.post("http://example.com/api/create", {name: "test"});

// 带header的POST请求
let result = axios.post("http://example.com/api/create", {name: "test"}, {
    headers: {
        "Content-Type": "application/json"
    }
});
```

**返回结果示例**

```json
{
    "data": {"id": 1, "name": "test"},
    "status": 201,
    "statusText": "Created",
    "responseHeaders": {}
}
```

## 响应结构

所有请求方法的返回结果都包含以下字段：

| **字段名**     | **类型** | **说明** |
| ----------- | ------ | ------ |
| data       | 任意    | 响应数据，arraybuffer时为Buffer |
| status     | number | HTTP状态码 |
| statusText | string | HTTP状态文本 |
| responseHeaders | object | 响应头 |

## 注意事项

1. 内部基于MarmotBridge实现，底层调用`MarmotBridge.get("_marmot_http").send()`
2. delete方法尚不支持请求体
3. responseType默认为"json"，可设为"arraybuffer"获取二进制数据
4. 响应数据会根据responseType自动处理：arraybuffer转为Buffer，否则转为UTF-8字符串
