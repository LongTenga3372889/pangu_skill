# auto-fill 自动填单
> summary: 场景驱动的自动填单转换工具，将请求参数按模板映射为响应参数
> 引用路径: @M/v1/auto-fill

**引入**

```javascript
let autoFill = require("@M/v1/auto-fill");
```

## translateData
根据场景和模板进行数据转换

**描述**

* 根据场景编码和模板编码，将请求参数转换为响应参数
* 用于自动化填单场景，减少人工录入工作量
* 数据转换逻辑在后端配置

**名称**

* translateData

**入参**

| **参数名**     | **必输** | **类型** | **默认值** | **说明**                     |
| --------------- | ------ | ------ | ------- | -------------------------- |
| sceneCode | 是      | string | 空       | 场景编码|
| templateCode | 是      | string | 空       | 模板编码|
| requestParam | 是      | object | 空       | 请求参数对象|
| responseParam | 否      | object | {}      | 响应参数对象|

#### 使用示例

```javascript
let result = autoFill.translateData({
    sceneCode: "PURCHASE_ORDER_FILL",
    templateCode: "STANDARD_PO_TEMPLATE",
    requestParam: {
        supplierCode: "SUP001",
        materialCode: "MAT2024001",
        quantity: 100
    },
    responseParam: {}
});
STD.Logger.info("translateData: {}", result);
```

**返回结果示例**

```json
{
  "supplierName": "上海甄云信息科技有限公司",
  "materialName": "办公用品A4纸",
  "unitPrice": 25.50,
  "totalAmount": 2550.00,
  "deliveryDate": "2024-12-31"
}
```

#### 注意事项

* `sceneCode`和`templateCode`需在系统中预配置
* `requestParam`的结构和字段需与模板匹配
* 转换规则在后端定义，前端只负责传入原始数据和接收转换结果
