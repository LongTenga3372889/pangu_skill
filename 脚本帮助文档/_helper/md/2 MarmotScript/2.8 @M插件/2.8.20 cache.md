# cache 缓存
> summary: 基于内存的键值缓存，支持过期时间设置与分布式锁
> 引用路径: @M/v1/cache
缓存工具
> 如不设定过期时间，则默认 2 hour 后过期
>

**引入**
```javascript
let cache = require("@M/v1/cache");
```
***
### put
设置缓存

| **参数名**     | **必输** | **类型** | **默认值** | **说明**                     |
| --------------- | ------ | ------ | ------- | -------------------------- |
| key | 是      | string | 空       | 缓存KEY|
| object | 是      | string | 空       | 要缓存的数据字符串|
| expireTime | 是      | string| 空       | 过期时间(秒)-默认2个小时|

```javascript
cache.put({key:"chaofan", object:"{nam"});
```
***
### get
获取缓存消息

| **参数名**     | **必输** | **类型** | **默认值** | **说明**                     |
| --------------- | ------ | ------ | ------- | -------------------------- |
| key | 是      | string | 空       | 缓存KEY|

```javascript
cache.get({key:"chaofan"})
```
***
### remove
清除缓存消息

| **参数名**     | **必输** | **类型** | **默认值** | **说明**                     |
| --------------- | ------ | ------ | ------- | -------------------------- |
| key | 是      | string | 空       | 缓存KEY|

```javascript
cache.remove({key:"chaofan"})
```
***
### computeIfAbsent
存在则获取，不存在则执行函数加载值并获取

| **参数名**     | **必输** | **类型** | **默认值** | **说明**                     |
| --------------- | ------ | ------ | ------- | -------------------------- |
| key | 是      | string | 空       | 缓存KEY|
| func                  | 是      | function | 空       | 执行函数   |
| expireTime | 是      | string| 空       | 过期时间(秒)-默认2个小时|

```javascript
cache.getIfPresent({key:"chaofan", func:()=>{
        STD.Logger.info("123456788");
        return "789";
    }, expireTime:100});
```



### withLock
简陋的锁实现
如未得到锁，并不会等待或重试  
func执行完成后，锁即会释放  
exceptionOnLockNotGot：默认抛出异常，如不抛出，则func不会被执行

| **参数名**               | **必输** | **类型**   | **默认值** | **说明**   |
|-----------------------|--------|----------|---------|----------|
| key                   | 是      | string   | 空       | 缓存KEY    |
| func                  | 是      | function | 空       | 执行函数     |
| exceptionOnLockNotGot | 否      | bollean  | false   | 未得到锁是否报错 |

```javascript
cache.withLock({key:"chaofan", func:()=>{
        STD.Logger.info("123456788");
        return "789";
    }, exceptionOnLockNotGot:false});
```
