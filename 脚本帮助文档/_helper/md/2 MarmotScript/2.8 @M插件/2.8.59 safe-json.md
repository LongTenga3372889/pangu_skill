# safe-json 安全JSON工具
> summary: 安全JSON工具，提供parse/stringify方法处理JSON，支持过滤不安全内容
> 引用路径: @M/v1/safe-json

**引入**
```javascript
let safeJson = require("@M/v1/safe-json").JSON;
// 或
const { JSON } = require("@M/v1/safe-json");
```

## 目录

* [parse](#parse)
* [stringify](#stringify)

***

### parse
安全解析JSON字符串

#### 描述

*   将JSON字符串解析为JavaScript对象，支持过滤不安全内容

#### 入参

| **参数名** | **必输** | **类型** | **默认值** | **说明**   |
| ------- | ------ | ------ | ------- | -------- |
| jsonStr | 是      | string | 空       | JSON字符串 |

#### 返回结果

| **类型** | **说明**   |
| ------ | -------- |
| object | 解析后的对象 |

#### 使用示例

```javascript
function process(input) {
    let safeJson = require("@M/v1/safe-json").JSON;
    let jsonStr = '{"name":"test","value":123}';
    let obj = safeJson.parse(jsonStr);
    STD.Logger.info("parsed: {}", obj);
}
```

#### 注意

*   入参必须是字符串类型，否则会抛出异常
*   空值或空字符串会直接返回

***

### stringify
安全序列化对象为JSON

#### 描述

*   将JavaScript对象序列化为JSON字符串，支持过滤不安全内容

#### 入参

| **参数名** | **必输** | **类型** | **默认值** | **说明**  |
| ------- | ------ | ------ | ------- | ------- |
| obj     | 是      | object | 空       | JavaScript对象 |

#### 返回结果

| **类型** | **说明**   |
| ------ | -------- |
| string | 序列化后的JSON字符串 |

#### 使用示例

```javascript
function process(input) {
    let safeJson = require("@M/v1/safe-json").JSON;
    let obj = { name: "test", value: 123 };
    let jsonStr = safeJson.stringify(obj);
    STD.Logger.info("stringified: {}", jsonStr);
}
```

#### 注意

*   如果对象序列化后为空，会直接返回空字符串
