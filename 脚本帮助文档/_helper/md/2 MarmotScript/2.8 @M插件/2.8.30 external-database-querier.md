# external-database-querier 外部数据库查询工具
> summary: 外部数据库查询工具，支持预配置数据源的selectList/selectOne/selectPage查询
> 引用路径: @M/v1/external-database-querier
外部数据库查询工具

**引入**
```javascript
  let extQuerier = require("@M/v1/external-database-querier");
```
## 目录

* [selectList](#selectList)
* [selectOne](#selectOne)
* [selectPage](#selectPage)

### 注意：
>使用该方法的前置配置：
> 1. 在【Marmot工作台】->【管理设定】->【MarmotExternalDatabase】进行数据源配置
> 2. 在【Marmot工作台】->【控制台】->【外部数据库查询器】进行配置
   

> 查询数据务必使用tenantId进行条件筛选,建议从UserDetails取当前角色tenantId
如特殊情况取不到当前tenantId，则（#{executionTenantId},代表该脚本的归属租户id）

>查询数据务必谨慎的关联平台数据，能少查几个字段，就少查几个字段，不要从Java代码中大段大段复制

>务必确保单次查询性能，每次查询超时时间为10s，非常严格

>为了性能更好，减少表join，尽可能为每个表都使用tenantId作为条件

>【外部数据库查询器】必须写明需求号

***

### selectList
查询数据列表

| **参数名**     | **必输** | **类型** | **默认值** | **说明**                     |
| --------------- | ------ | ------ | ------- | -------------------------- |
| code | 是      | string | 空       | 编码|
| param | 否      | object | {}       | 查询所需参数|

```javascript
let extQuerier = require("@M/v1/external-database-querier");
extQuerier.selectList({
    code:"TEST1", 
    param:{userId:"496015"}
});
```

### selectPage
查询分页数据

| **参数名**     | **必输** | **类型** | **默认值** | **说明**                     |
| --------------- | ------ | ------ | ------- | -------------------------- |
| code | 是      | string | 空       | 编码|
| param | 否      | object | {}       | 查询所需参数|
| pageRequest | 是      | object | 空       | 分页参数|

```javascript
let extQuerier = require("@M/v1/external-database-querier");
extQuerier.selectPage({
    code:"TEST1",
    param:{userId:"496015"},
    pageRequest:{page:0,size:10}
});
```
