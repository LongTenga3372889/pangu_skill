#### workbookQuickGenerate——快速生成workbook
简介：
    可快速生成多sheet页workbook。快速生成的头行即传入对象的key，如有需要需自行修改头行。

入参：

| 参数名        | 必输 | 类型    | 默认值 | 说明          |
| ---------- | --- | ----- | --- | ----------- |
| jsonSource | 是  | array | 空   | object类型数据源 |

```javascript
//对象格式数据源
let jsonSource = [{"a":1}, {"a":2}];
let workbook = xlsx_supporter.workbookQuickGenerate(jsonSource);
```

#### importHeaders——导入头行

入参：

| 参数名         | 必输 | 类型     | 默认值  | 说明           |
| ----------- | --- | ------ | ---- | ------------ |
| worksheet   | 是  | object | 空    | xlsx工具生成的表对象 |
| arraySource | 是  | array  | 空    | 数组类型数据源      |
| origin      | 否  | string | A1   | 插入起点         |
| style       | 否  | object | h1样式 | 单元格样式        |

```javascript
let origin = "A1";    //格式为"B1"，即起始单元格地址，默认为“A1”
let style = {
    font : {
                sz : 11,
                bold : true
            }
}
xlsx_supporter.importHeaders(worksheet, ["h1", "h2"], origin, style);
```

#### importCells——批量导入单元格

入参：

| 参数名         | 必输 | 类型     | 默认值  | 说明           |
| ----------- | --- | ------ | ---- | ------------ |
| worksheet   | 是  | object | 空    | xlsx工具生成的表对象 |
| arraySource | 是  | array  | 空    | 数组类型数据源      |
| origin      | 否  | string | A1   | 插入起点         |
| style       | 否  | object | c1样式 | 单元格样式        |
| columnStyles      | 否  | array | 空    | 单元格样式        |
| columnTypes       | 否  | array | 空    | 单元格数据类型     |

```javascript
let origin = "A1";    //格式为"B1"，即起始单元格地址，默认为“A1”
let style = {
    font : {
                sz : 11,
                bold : true
            }
}
//不传取默认，默认style参数的值
let columnStyles = [null,null,style];
//不传取默认，默认数据类型是s---s是文本，n是数字，d是Date， b是布尔
let columnTypes = ["s",null,"n"];
xlsx_supporter.importCells(worksheet, [[1,2,3],[4,5,6]], origin, style, columnStyles, columnTypes);
```

#### addImage——添加图片到Excel
简介：
    将图片添加到Excel工作簿的指定位置。支持多个图片同时添加，支持指定工作表、起始和结束坐标。

入参：

| 参数名       | 必输 | 类型     | 默认值 | 说明           |
| --------- | --- | ------ | --- | ------------ |
| fileBytes | 是  | byte[] | 空   | 原始Excel文件的字节数组 |
| info      | 是  | string | 空   | JSON格式的图片信息数组，每个对象包含图片信息 |

**info参数说明**：
每个图片信息对象包含以下字段：

| 字段名      | 必输 | 类型     | 默认值 | 说明           |
| ---------- | --- | ------ | --- | ------------ |
| fileUrl    | 是  | string | 空   | 图片文件的URL地址 |
| sheetName  | 否  | string | 第一个sheet页名称 | 图片要插入的工作表名称 |
| row        | 是  | number | 空   | 图片起始行号（从0开始） |
| col        | 是  | number | 空   | 图片起始列号（从0开始） |
| row2       | 是  | number | 空   | 图片结束行号（从0开始） |
| col2       | 是  | number | 空   | 图片结束列号（从0开始） |

**图片类型支持**：
- `.png` -> PNG格式
- `.jpg` 或 `.jpeg` -> JPEG格式
- `.bmp` -> DIB格式
- 其他格式 -> 默认为PNG格式

示例：

```javascript
// 示例1：添加单张图片
let xlsxHelper = require('@M/v1/xlsx-support').xlsxHelper;
let fileBytes = STD.Attachment.queryBytes(123); // 获取原始Excel文件
let info = JSON.stringify([
  {
    "fileUrl": "/images/logo.png",
    "sheetName": "Sheet1",
    "row": 0,
    "col": 0,
    "row2": 2,
    "col2": 2
  }
]);
let result = xlsxHelper.addImage(fileBytes, info);

// 示例2：添加多张图片
let info2 = JSON.stringify([
  {
    "fileUrl": "/images/logo.png",
    "sheetName": "Sheet1",
    "row": 0,
    "col": 0,
    "row2": 2,
    "col2": 2
  },
  {
    "fileUrl": "/images/qr_code.jpg",
    "sheetName": "Sheet2",
    "row": 5,
    "col": 5,
    "row2": 7,
    "col2": 7
  }
]);
let result2 = xlsxHelper.addImage(fileBytes, info2);
```

**注意事项**：
1. 图片文件通过`fileUrl`指定，图片文件存储在私有存储桶中
2. 图片坐标系统基于Excel的行列索引，从0开始计算
3. 如果指定的工作表不存在，会自动创建该工作表
4. 图片会填充在指定的矩形区域内（从(row, col)到(row2, col2)）
5. 方法返回添加图片后的Excel文件字节数组
6. 图片文件需要先上传到文件服务，获取fileUrl后才能使用

### 标准样式

*   h1 ,14号加粗，灰色背景

*   h2 ，16号

*   h2 ，16号加粗，灰色背景

*   c1 ，11号，黑色字体

*   c2 ，11号, 字体黄色

*   c3 ，11号, 背景黄色
