# 对象操作器-全局
> summary: 全局对象访问工具，仅允许读取系统级配置表数据，不支持写入操作
> 引用路径: @M/v1/object-global

***

> 仅用于访问 全局对象   
> 包含 '系统级配置表'   
> 仅包含数据访问功能，不允许写入
# 引入

```javascript
const objectOperation = require("@M/v1/object-global");
```

# 使用案例

```javascript
function process(input) {
    let objectOperation = require("@M/v1/object-global");
    /*
    操作表 sslm_investigate_tpl_config
       */
    let res = objectOperation.query({object:"sslm_investigate_tpl_config",condition:{}})
    return { res };
}
```
