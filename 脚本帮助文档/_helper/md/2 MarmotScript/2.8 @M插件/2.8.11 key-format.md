# key-format
> summary: RSA密钥格式转换工具，支持Java密钥与PEM密钥互转
> 引用路径: @M/v1/key-format
> 用于 RSA秘钥的格式转换

## 概念
>Java的秘钥与PEM秘钥格式不同，常常需要转换以混合使用  
>秘钥对的生成可参考 keypair(在另一篇文档中)   

## 引入
```javascript
const keyFormat=require('@M/v1/key-format');
```
## Java秘钥对转换为PEM秘钥对

```javascript
const keyFormat=require('@M/v1/key-format');

pemPrivate=keyFormat.javaPrivate2PEM('Java生成的私钥');

pemPulic=keyFormat.javaPublic2PEM('Java生成的私钥');

```
