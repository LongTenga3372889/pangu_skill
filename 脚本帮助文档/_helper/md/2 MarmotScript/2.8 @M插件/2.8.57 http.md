# http HTTP请求工具
> summary: HTTP GET请求工具，支持url/parameters/headers参数，返回responseBody/response/error/errorMessage
> 引用路径: @M/v1/http

**引入**
```javascript
let http = require("@M/v1/http");
```

## 目录

* [get](#get)

***

### get
发送HTTP GET请求

#### 描述

*   发送GET请求到指定URL，支持传入查询参数和请求头

#### 入参

| **参数名**   | **必输** | **类型** | **默认值** | **说明**     |
| ----------- | ------ | ------ | ------- | ---------- |
| url         | 是      | string | 空       | 请求地址      |
| parameters  | 否      | object | {}      | 查询参数对象   |
| headers     | 否      | object | {}      | 请求头对象    |

#### 返回结果

| **字段名**      | **类型** | **说明**   |
| ------------- | ------ | -------- |
| responseBody  | string | 原始响应字符串 |
| response      | object | 解析后的JSON对象 |
| error         | boolean | 是否出错   |
| errorMessage  | string | 错误信息   |

#### 使用示例

```javascript
function process(input) {
    let http = require("@M/v1/http");
    let result = http.get({
        url: "https://api.example.com/data",
        parameters: { id: "123", name: "test" },
        headers: { "Authorization": "Bearer token123" }
    });
    STD.Logger.info("response: {}", result.response);
    return result;
}
```

#### 返回结果示例

```json
{
  "responseBody": "{\"code\":200,\"data\":{\"id\":\"123\",\"name\":\"test\"}}",
  "response": { "code": 200, "data": { "id": "123", "name": "test" } },
  "error": false,
  "errorMessage": null
}
```
