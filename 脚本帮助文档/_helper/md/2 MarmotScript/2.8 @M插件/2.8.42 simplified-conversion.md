# simplified-conversion 繁简转换
> summary: 中文繁简体转换工具，支持大陆简体、台湾简体与繁体中文互转
> 引用路径: @M/v1/simplified-conversion

中文繁简体转换-区分大陆简体繁体和台湾简体繁体
> 更多详细实现见: com.github.houbb的opencc4j依赖

**引入**
```javascript
  let simplifiedConversionHelper = require("@M/v1/simplified-conversion");
```


***
### isSimple
是否全部为简体中文

#### 入参

| **参数名** | **必输** | **类型**  | **默认值** | **说明**  |
|---------|--------|---------|---------|---------|
| chinese | 是      | string  | 空       | 中文      |
| tw      | 否      | boolean | false   | 是否是台湾中文 |

#### 使用示例

```javascript
function process(input) {
    let simplifiedConversionHelper = require("@M/v1/simplified-conversion")
    STD.Logger.info("你还会回来吗 isSimple: {}",simplifiedConversionHelper.isSimple("你还会回来吗", true));
    // 打印结果： 
    // 你还会回来吗 isSimple: true
}

```

### toSimple
是否转换为简体中文

#### 入参

| **参数名** | **必输** | **类型**  | **默认值** | **说明**    |
|---------|--------|---------|---------|-----------|
| chinese | 是      | string  | 空       | 汉字        |
| tw      | 否      | boolean | false   | 是否转换为台湾简体 |

#### 使用示例

```javascript
function process(input) {
    let simplifiedConversionHelper = require("@M/v1/simplified-conversion")
    STD.Logger.info("么 toSimple: {}",simplifiedConversionHelper.toSimple("么"));
    STD.Logger.info("么 toSimple tw: {}",simplifiedConversionHelper.toSimple("么", true));
    // 打印结果： 
    // 么 toSimple: 么
    // 么 toSimple tw: 幺
}

```
