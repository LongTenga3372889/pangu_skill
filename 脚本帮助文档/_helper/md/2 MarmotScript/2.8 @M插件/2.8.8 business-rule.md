# business-rule 业务规则执行器
> summary: 业务规则执行器，通过服务编码执行业务规则并返回结果
> 引用路径: @M/v1/business-rule

用于执行业务规则   

**引入**

```javascript
let user = require("@M/v1/business-rule");
```

***

### 执行某规则

**描述**

*   执行某规则

**名称**

*   execute

**入参**

| 参数名         | 必输  | 类型     | 默认值 | 说明        |
|-------------|-----| ------ | --- |-----------|
| serviceCode | yes | string | 空   | 业务规则的服务编码 |
| object      | yes | {} | 空   | 规则所需参数    |

**使用示例**

```javascript
const BusinessRule = require("@M/v1/business-rule");
const result = BusinessRule.execute({
    serviceCode: "SITE.SMAL.PURCHASE_PRICE_RULES",
    object: {}//不同的服务所需参数不同
});
```
