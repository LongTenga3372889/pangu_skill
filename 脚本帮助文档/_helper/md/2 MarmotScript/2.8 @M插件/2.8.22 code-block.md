# codeBlock 代码块
> summary: 远程代码块执行工具，支持execute和run两种调用
> 引用路径: @M/v1/code-block
代码块使用工具
>使用该方法需要在MarmotScript控制台中的CodeBlock配置项进行配置

> 唯一标识编码字段需要全部大写

**引入**
```javascript
let codeblock = require("@M/v1/code-block");
```
***
### execute
执行代码块

| **参数名**     | **必输** | **类型** | **默认值** | **说明**                     |
| --------------- | ------ | ------ | ------- | -------------------------- |
| code | 是      | string | 空       | codeblock编码|
| input | 是      | string | 空       | 传入参数|

```javascript
codeblock.execute({
    code:"ANY_CODE", 
    input:[1,2,3]
});
```
***
### run
执行代码块，用来执行传入参数格式是{***}的代码块

| **参数名**     | **必输** | **类型** | **默认值** | **说明**                     |
| --------------- | ------ | ------ | ------- | -------------------------- |
| code | 是      | string | 空       | codeblock编码|
| input | 是      | string | 空       | 传入参数|

```javascript
codeblock.run({
    code:"ANY_CODE",
    input:{a:1}
});
```
