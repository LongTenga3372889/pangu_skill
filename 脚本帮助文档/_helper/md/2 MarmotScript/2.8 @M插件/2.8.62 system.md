# system 系统工具
> summary: 系统工具集，提供延迟执行、缓存失效、日志记录等基础系统能力
> 引用路径: @M/v1/system

**引入**
```javascript
let system = require("@M/v1/system");
```

***

## sleep

延迟执行（暂停当前脚本）

#### 入参

| **参数名** | **必输** | **类型** | **默认值** | **说明** |
| --------- | ------ | ------ | ------- | ------ |
| millis | 是 | number | 空 | 延迟毫秒数 |

#### 使用示例

```javascript
function process(input) {
    let system = require("@M/v1/system");
    STD.Logger.info("开始等待...");
    system.sleep(3000); // 等待3秒
    STD.Logger.info("等待结束");
}
```

***

## invalidLivingCache

失效指定缓存

#### 入参

| **参数名** | **必输** | **类型** | **默认值** | **说明** |
| --------- | ------ | ------ | ------- | ------ |
| livingCacheName | 是 | string | 空 | 缓存名称 |
| key | 是 | string | 空 | 缓存Key |

#### 使用示例

```javascript
function process(input) {
    let system = require("@M/v1/system");
    system.invalidLivingCache("user_cache", "user_123");
}
```

***

## invalidAllLivingCache

失效所有缓存

#### 入参

无

#### 使用示例

```javascript
function process(input) {
    let system = require("@M/v1/system");
    system.invalidAllLivingCache();
}
```

## changeLog

记录变更日志

#### 入参

| **参数名** | **必输** | **类型** | **默认值** | **说明** |
| --------- | ------ | ------ | ------- | ------ |
| type | 是 | string | 空 | 日志类型 |
| content | 是 | string | 空 | 日志内容 |

#### 使用示例

```javascript
function process(input) {
    let system = require("@M/v1/system");
    system.changeLog("ORDER_UPDATE", "订单状态从PENDING变更为COMPLETED");
}
```
