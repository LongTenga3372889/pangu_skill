# mdm MDM主数据工具
> summary: MDM主数据工具，提供日历查询（节假日/工作日）和组织架构（OU）查询能力
> 引用路径: @M/v1/mdm

**引入**
```javascript
let mdm = require("@M/v1/mdm");
// 或使用别名
let mdm = require("@M/v1/mdm").OU;
```

## calendar 日历工具

### isOfficialHoliday
判断是否为法定节假日

#### 描述

*   根据国家和日期判断是否为法定节假日

#### 入参

| **参数名**   | **必输** | **类型** | **默认值** | **说明**   |
| ----------- | ------ | ------ | ------- | -------- |
| countryCode | 否      | string | "CN"    | 国家代码   |
| date        | 否      | string | 今天     | 日期，格式YYYY-MM-DD |

#### 使用示例

```javascript
function process(input) {
    let mdm = require("@M/v1/mdm");
    let isHoliday = mdm.calendar.isOfficialHoliday({
        countryCode: "CN",
        date: "2026-01-01"
    });
    STD.Logger.info("is holiday: {}", isHoliday);
}
```

## operationUnit / OU 组织单元查询

### query
查询组织单元

#### 描述

*   根据公司ID/OU ID/OU Code查询组织单元信息

#### 入参

| **参数名** | **必输** | **类型**   | **默认值** | **说明**  |
| -------- | ------ | -------- | ------- | ------- |
| companyId | 否     | Long     | 空       | 公司ID   |
| ouId     | 否     | Long     | 空       | 组织单元ID |
| ouCode   | 否     | string   | 空       | 组织单元编码 |

#### 使用示例

```javascript
function process(input) {
    let mdm = require("@M/v1/mdm");
    // 根据ouCode查询
    let ouResult = mdm.operationUnit.query({
        companyId: 7690,
        ouCode: "OU001"
    });
    STD.Logger.info("ou result: {}", ouResult);

    // 或使用别名
    let ouResult2 = mdm.OU.query({
        ouId: 12345
    });
}
```
