# doc-authority 单据权限
> summary: 用户单据数据权限查询，支持平铺和树形结构返回
> 引用路径: @M/v1/doc-authority

**引入：**

```javascript
let docAuthHelper = require("@M/v1/doc-authority");
```

## 查询用户数据权限（selectFlatUserAuthority）--平铺

**描述**

*   根据条件查询查询用户数据权限，查询带上当前脚本所属租户

**名称**

*   selectFlatUserAuthority

**入参**

| 参数名      | 必输 | 类型            | 默认值 | 说明     |
|----------| --- |---------------| --- |--------|
| roleId   | 是  | string｜number | 空   | 角色id   |
| userId   | 是  | string｜number         | 空   | 用户id   |
| docCode  | 是  | string        | 空   | 单据权限编码 |

#### 使用示例

```javascript

let result =  docAuthHelper.selectFlatUserAuthority({roleId:'__-ZZtg0WEg7UZhfENP40QKXw-__',userId:'8848',docCode:'SSRC_PRICE_LIBRARY_NEW'})

```

##  （过时）查询用户数据权限（selectUserAuthority）--存在树形结构 

**描述**

*   根据条件查询查询用户数据权限，返回的维值可能存在树形结构，树形结构收集了启用的节点至enableDataList中

**名称**

*   selectUserAuthority

**入参**

| 参数名      | 必输 | 类型            | 默认值 | 说明     |
|----------| --- |---------------| --- |--------|
| tenantId | 是  | string｜number         | 空   | 当前租户id |
| roleId   | 是  | string｜number | 空   | 角色id   |
| userId   | 是  | string｜number         | 空   | 用户id   |
| docCode  | 是  | string        | 空   | 单据权限编码 |

#### 使用示例

```javascript

let result = docAuthHelper.selectUserAuthority(tenantId,roleId,userId,docCode)

```
