# queue 队列
> summary: Marmot消息队列发送工具，支持向指定topic发送消息
> 引用路径: @M/v1/queue
消息队列工具

**引入**
```javascript
let queue = require("@M/v1/queue");
```

***
### produce
只发送marmot队列消息

| **参数名**     | **必输** | **类型** | **默认值** | **说明**                     |
| --------------- | ------ | ------ | ------- | -------------------------- |
| topic | 是      | string | 空       | 队列主题编码|
| body | 是      | string| 空       | 参数|

```javascript
queue.produce({topic:"MARMOT_STD_CASE_QUEUE_TEST", body:{"tmpObj":"test"}});
```
