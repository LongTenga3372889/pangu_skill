# seal-generator 印章生成器
> summary: 印章生成工具，通过Feign调用srm-file服务生成PNG格式印章图片
> 引用路径: @M/v1/seal-generator

**引用路径：** @M/v1/seal-generator

**功能描述：** 生成印章（签章）图片，通过Feign调用srm-file服务生成PNG格式印章图片。

---

## 目录

* [生成印章---generateSeal](#生成印章)

## 生成印章

#### 描述

* 调用srm-file服务生成印章图片，返回PNG格式的图片Buffer

#### 名称

* generateSeal

#### 入参

| **参数名**    | **必输** | **类型** | **默认值** | **说明** |
| ---------- |--------| ------ |---------|---------|
| width | 否 | number | 200 | 图片宽度，单位像素 |
| height | 否 | number | 200 | 图片高度，单位像素 |
| bgColor | 否 | string | "200,40,40" | 背景色RGB值，格式："R,G,B" |
| bgAlpha | 否 | number | 230 | 背景透明度，范围0-255，255为不透明 |
| transparent | 否 | boolean | false | 是否透明背景，true时忽略bgColor |
| borderWidth | 否 | number | 3 | 外边框宽度 |
| innerBorderWidth | 否 | number | 1.5 | 内边框宽度 |
| showInnerBorder | 否 | boolean | true | 是否显示内边框 |
| padding | 否 | number | 10 | 边框内部边距 |
| firstLineStartY | 否 | number | 30 | 第一行文字起始Y坐标 |
| lineSpacing | 否 | number | 30 | 行间距 |
| textColor | 否 | string | "255,255,255" | 文字颜色RGB值，格式："R,G,B" |
| borderColor | 否 | string | "160,30,30" | 边框颜色RGB值，格式："R,G,B" |
| texts | 否 | Array | - | 文字内容列表，详见下方说明 |

**texts数组元素参数：**

| **参数名**    | **必输** | **类型** | **默认值** | **说明** |
| ---------- |--------| ------ |---------|---------|
| text | 是 | string | - | 文字内容 |
| bold | 否 | boolean | false | 是否粗体 |
| fontSize | 否 | number | 16 | 字体大小 |
| align | 否 | string | "CENTER" | 对齐方式：LEFT/CENTER/RIGHT |
| rotation | 否 | number | 0 | 旋转角度，单位度 |
| marginTop | 否 | number | 0 | 上边距 |
| marginBottom | 否 | number | 0 | 下边距 |

#### 使用示例

##### 示例1：生成默认印章

```javascript
let sealGenerator = require("@M/v1/seal-generator");

// 不传任何参数，生成默认印章（红色背景，显示"验"字）
var sealBytes = sealGenerator.generateSeal({});
```

##### 示例2：完整参数示例（推荐使用）

```javascript
let sealGenerator = require("@M/v1/seal-generator");

// 完整参数示例，与srm-file服务保持一致
var sealBytes = sealGenerator.generateSeal({
    width: 350,
    height: 130,
    bgColor: "255,255,255",
    bgAlpha: 0,
    transparent: false,
    borderWidth: 3,
    innerBorderWidth: 1,
    padding: 10,
    textColor: "0,72,101",
    borderColor: "0,72,101",
    showInnerBorder: false,
    firstLineStartY: 30,
    lineSpacing: 20,
    texts: [
        {"text": "APPROVED IN CMS", "bold": true, "fontSize": 25},
        {"text": "Approval Ref: 1364854748", "bold": false, "fontSize": 16},
        {"text": "Date: 15 May 2025", "bold": false, "fontSize": 16},
        {"text": "Term:2025-04-01-2025-08-31", "bold": false, "fontSize": 16}
    ]
});
```

#### 出参描述

| **参数名**    | **类型** | **说明** |
| ---------- | ------ |--------|
| sealBytes | Buffer | PNG格式印章图片的Buffer |

#### 返回值使用场景

```javascript
let sealGenerator = require("@M/v1/seal-generator");

// 场景1：直接使用Buffer
var sealBytes = sealGenerator.generateSeal({texts: [{text: "测试"}]});

// 场景2：转换为Base64用于前端展示
var base64 = Buffer.from(sealBytes).toString('base64');
var htmlImg = "<img src='data:image/png;base64," + base64 + "' />";

// 场景3：上传到附件服务
var attachment = $M.attachment.uploadToAttachment({
    buffer: sealBytes,
    fileName: "seal.png",
    uuid: $M.attachment.getAttachmentUUID()
});
```
