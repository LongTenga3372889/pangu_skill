# jneon-client Jneon客户端
> summary: Jneon系统对接工具，提供HMAC-SHA256签名的GET/POST请求封装
> 引用路径: @M/v1/jneon-client

Jneon 系统对接工具

**引入**

```javascript
//引包
const JneonClient = require("@M/v1/jneon-client");
```

***

### getRequest

GET 请求

#### 入参

| **参数名**    | **必输** | **类型** | **默认值** | **说明**         |
|------------|--------|--------|---------|----------------|
| config     | 是      | object | 空       | 配置信息          |
| url        | 是      | string | 空       | 请求 URL         |
| params     | 是      | object | 空       | 请求参数          |

#### config 参数说明

| **参数名**      | **必输** | **类型** | **默认值** | **说明**   |
|--------------|--------|--------|---------|----------|
| clientId     | 是      | string | 空       | 客户端 ID   |
| clientSecret | 是      | string | 空       | 客户端密钥   |

#### 使用示例

```javascript
function process(input) {
    //引包
    const JneonClient = require("@M/v1/jneon-client");
    
    //配置信息
    const config = {
        clientId: "test",
        clientSecret: "test"
    };
    
    //请求参数
    const params = {
        invoiceCode: "5000192130",
        invoiceNumber: "00842030",
        billingDate: "2019-10-29",
        totalAmount: "9523.81"
    };
    
    //执行 GET 请求
    const result = JneonClient.getRequest(
        config,
        "http://218.94.72.202:19090/mars/api/check/invoice",
        params
    );
    
    return {result: result};
}
```

**返回结果格式示例**

```json
{
  "result": {
    "success": true,
    "body": "{\"code\":\"200\",\"message\":\"success\",\"data\":{...}}"
  }
}
```

### 技术说明

- 基于原 `com.fapiao.jneon.util.NewCallHelper` 重构
- 使用 HMAC-SHA256 签名认证机制
- 支持 GET/POST 请求
- 自动处理请求头签名和 Content-MD5 计算
- 零外部依赖，使用项目现有基础设施

### 注意事项

1. 确保目标主机在白名单中
2. 配置信息中的 clientId 和 clientSecret 需要正确设置
3. 请求参数需要符合目标 API 的要求
4. 响应结果中的 body 字段为字符串，需要根据实际情况解析
