# language
> summary: 多语言工具，支持消息内容翻译和平台多语言信息查询
> 引用路径: @M/v1/language
多语言工具

**引入**
```javascript
let language = require("@M/v1/language");
```
***
### getMessage
获取返回信息

| **参数名**     | **必输** | **类型** | **默认值** | **说明**                     |
| --------------- | ------ | ------ | ------- | -------------------------- |
| code | 是      | string | 空       | 返回消息编码|
| args | 是      | array | 空       | 返回消息参数|

```javascript
language.getMessage({code:"error.ssrc.quotation.quotation_detail_equal_strong_control",args:["aaa","bbb"]})
//输出 >> '操作失败,失败原因是【aaa】行号【bbb】报价明细总价需要等于物料行价格，请检查并修改'
```
***

***
### getPrompt
获取平台多语言信息

| **参数名**     | **必输** | **类型** | **默认值** | **说明**                     |
| --------------- | ------ | ------ | ------- | -------------------------- |
| code | 是      | string | 空       | 多语言编码|

```javascript
language.getPrompt({code:"ssrc.inquiryHall,model.inquiryHall.rfxByName"});
//输出 >> '询价员'
```
