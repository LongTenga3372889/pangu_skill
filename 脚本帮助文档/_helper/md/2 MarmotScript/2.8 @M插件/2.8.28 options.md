# options 配置项
> summary: 运行时环境配置获取，支持获取Marmot配置项和环境变量
> 引用路径: @M/v1/options
获取Marmot配置项
执行时基本信息的获取

**引入**

```javascript
let options = require("@M/v1/options");
```

***

### 获取Marmot配置项



```javascript
let option = require("@M/v1/options").getMarmotOption("develop_env_tag");
```
***

### 获取Marmot环境变量



```javascript
let option = require("@M/v1/options").getMarmotEnvVar("test_var");
```
