# Buffer
> Buffer MarmotScript中字节数组的载体,用于各类需要low-level操作字节的场景

## 概念
>MarmotScript中处理非纯文本类需求，会使用到Buffer   
>Buffer在MarmotScript中的实现并非是真正的Stream,而是字节数组   
>故处理文件时请尽量减小Buffer产生量，避免触发内存控制导致执行报错

## 引入
```javascript
//Buffer已作为全局变量引入,可直接使用
let testBuffer=Buffer.from('测试');
//也可以单独引入，在某些特殊场景下
const Buffer = require("buffer/").Buffer;
```

## 编解码
```javascript
//BASE64
const testStr='测试';
const base64edText=Buffer.from(testStr).toString('base64');
const plainText=Buffer.from(base64edText,'base64').toString();//toString 等效 toString('utf-8')

//Hex
const testStr='测试'
const hexText=Buffer.from(testStr).toString('hex');
const plainText=Buffer.from(hexText,'hex').toString();
```

## 字节流传输

```javascript
//任何获得文件内容的方法均返回Buffer，参考attachment,xlsx等

//下面以文件压缩为例
const zlib = require("zlib");

// Declaring input and assigning
// it a value string
let input = "Geeks";
let output = undefined;
let compressedBuffer=undefined;//该变量在压缩执行后是压缩的结果的Buffer形式

// Calling deflate method
zlib.deflate(input, (err, buffer) => {
    compressedBuffer=buffer;
    // Calling inflate method
    zlib.inflate(buffer, (err, buffer) => {
        output = buffer.toString("utf8");
    });
});

```
