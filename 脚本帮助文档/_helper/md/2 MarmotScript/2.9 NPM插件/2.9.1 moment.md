## 获取时间戳 -- 转换时间戳为时间对象
> format()方法接受一串令牌并将其替换为其相应的值；  
> 这里获取时间戳传入 x | X 为固定写法，想了解更多传入值可参考官方文档format()方法的详细解读；  
> 官方文档地址：http://momentjs.cn/docs/

```javascript
//1.获取时间戳(以秒为单位)
moment().format('X') // 返回的时间戳为字符串类型   "1641785781"

moment().unix() // 返回的时间戳为数值型   1641785833

//2.获取时间戳(以毫秒为单位)
moment().format('x') // 返回的时间戳为字符串类型

moment().valueOf() // 返回的时间戳为数值型

+moment() // 返回的时间戳为数值型

//3.转换时间戳为时间对象
// 转换时间戳为时间对象---秒
moment.unix(Number) 

// 转换时间戳为时间对象---毫秒
moment(Number) 

//转换为时间对象后可通过format设置时间格式
moment.unix(Number).format("YYYY-MM-DD HH:mm:ss");
```

## 格式化时间
```javascript
//例： moment();  // 2022-01-10T05:44:43.982Z
//1.格式化年月日： 'xxxx年xx月xx日'
moment().format('YYYY年MM月DD日')    //"2022年01月10日"

//2.格式化年月日： 'xxxx-xx-xx'
moment().format('YYYY-MM-DD')   //"2022-01-10"

//3.格式化时分秒(24小时制)： 'xx时xx分xx秒'  
moment().format('HH时mm分ss秒')   //"13时46分23秒"

//4.格式化时分秒(12小时制)：
moment().format('hh:mm:ss')    //"01:41:51"

moment().format('hh:mm:ss a')  //"01:41:51 午後"

//5.格式化时间 "YYYY-MM-DD HH:mm:ss"
// hh 小写则为12小时制，大写为24小时制
moment().format('YYYY-MM-DD HH:mm:ss')   //"2022-01-10 17:35:04"

```

##  时间比较
>**isBefore :**  检查一个 moment 是否在另一个 moment 之前

```javascript
moment().isBefore(Moment|String|Number|Date|Array);

// 第二个参数用于确定精度，且不仅仅是要检查的单个值，因此使用 day 将会检查年份、月份、日期
moment().isBefore(Moment|String|Number|Date|Array, String);

moment('2010-10-20').isBefore('2010-10-21'); // true

moment('2010-10-20').isBefore('2010-12-31', 'year'); // false

moment('2010-10-20').isBefore('2011-01-01', 'year'); // true

```
> **isSame :**  检查一个 moment 是否与另一个 moment 相同


 ```javascript
 moment('2010-10-20 12:00:00').isSame('2010-10-20 12:00:00')  //true
 ```
> **isAfter :** 检查一个 moment 是否在另一个 moment 之后

 ```javascript
 moment('2010-10-20').isAfter('2010-10-20')   //false
 ```
>**isSameOrBefore ：**检查一个 moment 是否在另一个 moment 之前或与之相同


```javascript
 moment('2010-10-21').isSameOrBefore('2010-10-20')  //false
 ```
> **isSameOrAfter :** 检查一个 moment 是否在另一个 moment 之后或与之相同

```javascript
 moment('2010-10-21').isSameOrAfter('2010-10-20')   //true
 ```

>**isBetween :** 检查一个 moment 是否在其他两个 moment 之间
```javascript
moment().isBetween(moment-like, moment-like, String, String);
moment('2010-10-20').isBetween('2010-10-19', '2010-10-25'); // true
// 如果要将粒度限制为毫秒以外的单位，则将单位作为第三个参数传入。
moment('2010-10-20').isBetween('2010-01-01', '2012-01-01', 'year'); // false
moment('2010-10-20').isBetween('2009-12-31', '2012-01-01', 'year'); // true
```

## 获取时间 (一天的开始和结束)
```javascript
//1.获取今天0时0分0秒
moment().startOf('day')

//2.获取本周第一天(周日)0时0分0秒
moment().startOf('week')

//3.获取当前月第一天0时0分0秒
moment().startOf('month')

//4.获取今天23时59分59秒
moment().endOf('day')

//5.获取本周最后一天(周六)23时59分59秒
moment().endOf('week')

//6.获取当前月最后一天23时59分59秒
moment().endOf('month')

```

## 获取时间
```javascript
//例： moment().format("YYYY-MM-DD HH:mm:ss"); //  2022-01-10 11:27:40

moment().get('year');   // 2022
// 0 至 11
moment().get('month');   // 0

moment().get('date');  //   10

moment().get('hour');  //   11

moment().get('minute');  //27

moment().get('second');  // 40

moment().get('millisecond');

```
## 设置时间
```javascript
//例：moment().format("YYYY-MM-DD HH:mm:ss"); //  2022-01-10 11:27:40

moment().set('year', 2013);  // 2013-01-10 11:27:40

moment().set('month', 3);  // 2013-04-10 11:27:40

moment().set('date', 1);   // 2013-04-01 11:27:40

moment().set('hour', 13);  // 2013-04-01 13:27:40

moment().set('minute', 20);  // 2013-04-01 13:20:40

moment().set('second', 30);  // 2013-04-01 13:20:30

moment().set('millisecond', 123);

moment().set({'year': 2013, 'month': 3});

```
## 增加、减少时间改变原始moment
> 增加方法add 减少subtract  两者方法一样

```javascript
//例：moment().format("YYYY-MM-DD HH:mm:ss"); //  2022-01-10 11:27:40
//1.设置年
moment().add(1, 'years')    //  2023-01-10 11:27:40
moment().add({years: 1})    //  2024-01-10 11:27:40

//2.设置月
moment().add(1, 'months')   //  2024-02-10 11:27:40

//3.设置日期
moment().add(1, 'days')     //  2024-02-11 11:27:40

//4.设置星期
moment().add(1, 'weeks')   //  2024-02-18 11:27:40

//5.设置小时
moment().add(1, 'hours')   //  2024-02-18 12:27:40

//6.设置分钟
moment().add(1, 'minutes')  //  2024-02-18 12:28:40

//7.设置秒数
moment().add(1, 'seconds')   //  2024-02-18 12:28:41

```




## 获取两个日期之间的时间差
> 支持的度量有  `years`、 `months` 、 `weeks` 、 `days` 、 `hours` 、 `minutes`  和  `seconds`

```javascript

let start = moment().subtract(1, 'weeks')
let end = moment()

end.diff(start) // 返回毫秒数

end.diff(start, 'months') // 0

end.diff(start, 'weeks') // 1

end.diff(start, 'days') // 7

start.diff(end, 'days') // -7

```

## 时区的扩展moment-timezone
> moment-timezone 是一个moment的扩展库，用于处理时区，可以方便的将日期时间转换为其他时区。  
> 时区的设置支持HIAM.TIME_ZONE_UTC值集里的所有值，若发现存在不支持的值，请联系Marmot管理员

```javascript
const momentTz = require('moment-timezone');
//当前时间
momentTz();   //2024-09-10T02:48:33.470Z
momentTz().format("YYYY-MM-DD T HH:mm:ss.SSS Z");    //2024-09-10 T 10:48:33.486 +08:00

//示例一：当前时间转换成自定义时区的时间字符串
momentTz().tz('GMT+9') //2024-09-10T02:48:33.493Z
momentTz().tz('GMT+9').format("YYYY-MM-DD T HH:mm:ss.SSS Z") //2024-09-10 T 11:48:33.501 +09:00

//获取用户时区
STD.CurrentContext.getTimeZone();    //GMT+7

//示例二：获取用户时区的当前时间字符串(此方法1102迭代过后上正式)
momentTz.getCurrentUserTimeZoneDate("YYYY-MM-DD T HH:mm:ss.SSS Z");    //2024-09-18 T 16:33:16.448 +07:00
// 注：format参数不传默认YYYY-MM-DD HH:mm:ss

//示例三：将一个字符串时间按用户时区转换成moment对象
momentTz.tz.setDefault(STD.CurrentContext.getTimeZone());
momentTz("2024-08-13 10:07:37.355")  //2024-08-13T03:07:37.355Z

//示例四：将GMT+7的字符串时间转换成GMT+9的字符串时间
momentTz.tz.setDefault('GMT+7');
momentTz("2024-08-13 10:07:37.355").tz("GMT+9").format("YYYY-MM-DD T HH:mm:ss.SSS Z");   //2024-08-13 T 12:07:37.355 +09:00

//示例五：将GMT+7的字符串时间与GMT+9的字符串时间比较
momentTz.tz.setDefault('GMT+7');
let time1 = momentTz("2024-08-13 10:07:37.354");    //2024-08-13T03:07:37.354Z
momentTz.tz.setDefault('GMT+9');
let time2 = momentTz("2024-08-13 13:07:37.354");    //2024-08-13T04:07:37.354Z
time1.isAfter(time2);    //false
time1.isBefore(time2);   //true
time1.isSame(time2);   //false
time2.diff(time1);   //3600000
time2.diff(time1, 'hours');   //1

// 其他方法
// 用户时区猜测
momentTz.tz.guess(); // Asia/Shanghai
```
**注：**
> * momentTz.tz.setDefault作用在解析字符串时间的时候，对于format的时候是没有效果的
> * moment对象都是UTC时间，format时默认是服务器时区并非用户时区，可在初始化之后使用tz方法转换成其他时区
