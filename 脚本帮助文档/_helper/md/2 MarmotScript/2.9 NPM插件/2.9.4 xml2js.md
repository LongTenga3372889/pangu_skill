## xml2js 
>第三方XML解析器    
> 详细使用方式请参考官方文档   
>  https://github.com/Leonidas-from-XIV/node-xml2js


## 基本使用

### xml转object
```javascript
const parseString = require('xml2js').parseString;
const xml = "<root>Hello xml2js!</root>"
let resp=undefined;//解析好的对象
parseString(xml, function (err, result) {
    resp=result;
});

```

### object转xml
```javascript
let xml2js = require('xml2js');
let builder = new xml2js.Builder();
let obj = {"hello":["1","2","3"]};
let xml = builder.buildObject(obj);
```


## 关于XML

XML作为一种标签文本，是无法友好的直接转换为对象结构的(这一点与JSON区别)   
xml2js应用于无损的xml->object->xml,故其对象属性可读性会稍差，但不会损失任何数据  
如对其工作模式不满意，可进行调整(参考官方文档 Options 一章)

### 例1
```javascript
    xml2js = require('xml2js')
    let myParser=new xml2js.Parser({explicitArray:false});
    //这个parser在遇到单标签时，会自动处理为单个对象，而不是数组，常用语简单的短XML场景
```
