# keypair
> 用于 RSA秘钥对生成

## 概念
>一般的教程中，RSA秘钥使用openSSL生成  
>keypair 也可以生成，用于方便大家进行调试   

## 引入
```javascript
const keypair=require('keypair');
```
## 生成秘钥对

```javascript
const keypair=require('keypair');

//建议用于各场景的RSA秘钥长度不要超过512，否则性能吃不消
const pair=keypair({bits:512});

const private=pair.private;//私钥，PEM

const public=pair.public;//公钥，PEM

```
