# JSSheet-Excel快速开发

JSSheet是脚本中引入用于excel开发的node模块。

为了开发的便利我们封装了一些功能并把它们放在xlsx-support插件内。

在进行EXCEL开发前，你需要引入以下模块：

```json
let XLSX = require("xlsx");
let XLSX_STYLE = require("xlsx-style");
let xlsx_support = require("@M/v1/xlsx-support");

```

### 1.获取对象数组格式的数据源

```javascript
let datasource = [
    {
      "data1" : "我是数据",
      "data2" : "我也是数据"
    },
    {
      "data1" : "我是第二个的数据",
      "data2" : ""
    }
];
```

### 2.创建头行map映射

```javascript
let sourceMap = {
    "列1" : "data1",
    "列2" : "data2"
};
```

### 3.生成表格

```javascript
let worksheet = xlsx_support.jsonToSheetByMap(datasource, sourceMap);

let workbook = XLSX.utils.book_new();
XLSX.utils.book_append_sheet(workbook, worksheet, "表格1");
```

此时该表格式如下：

| data1    | data2     |
| -------- | --------- |
| 我是数据     | 我也是数据     |
| 我是第二个的数据 | 我也是第二个的数据 |

### 4.设置表格式

#### ·设置头格式

**说明**：生成表格后，默认头行h1样式，如有需要按此方法修改

style格式参考：[附1：style样式对象](#附1：style样式对象)

```javascript
let style = xlsx_support.common.header.h1;
//自定义style比如
style.font.sz = 18;    //设置字体大小为18
xlsx_support.setCellsStyle(worksheet, ”1“, style);    //1 后端整合翻译为 第一行
```

#### ·设置行格式

**说明**：生成表格后，默认普通行c1样式，如有需要按此方法修改

style格式参考：[附1：style样式对象](#附1：style样式对象)

```javascript
let style = xlsx_support.common.cell.c1;
//自定义style比如
style.font.sz = 18;    //设置字体大小为18
xlsx_support.setCellsStyle(worksheet, ”A2:“, style);    //A2: 后端整合翻译为 A2单元格至最后
```

#### ·合并单元格

**说明**：如需要合并单元格，按此方法合并。

```javascript
xlsx_support.mergeCells(worksheet, ”A1:A2“);    //此处范围不适用 1、A、A1: 这几种格式
```

#### ·设置列宽

**说明**：生成表格后，如需要设置列宽，有以下两种方法

①设置自适应列宽

```javascript
xlsx_support.autoSizeAllColumn(worksheet);
```

②手动调整列宽

```javascript
xlsx_support.setColWidth(worksheet, [0,1,2], 16)；  //参数：（表对象，列数组， 宽度）
```
#### ·设置行高
**说明**：生成表格后，如需要设置行高，可按以下方式设置
```javascript
xlsx_support.setRowHeight(worksheet, [0,1,3], 100); //设置第0、1、3行高度为100
```
#### ·设置行/列隐藏
**说明**：生成表格后，如需要设置行/列隐藏，可按以下方式设置
```javascript
/*隐藏第i + 1行*/
xlsx_support.hideRows(worksheet, [i]);
//或
worksheet['!rows'][i] = {hidden:true}

/*隐藏第j + 1列*/
xlsx_support.hideCols(worksheet, [j]);
//或
worksheet['!cols'][i] = {hidden:true}
```
#### ·设置分组
**说明**：生成表格后，如需要设置分组，可按以下方式设置
```javascript
xlsx_support.groupRows(worksheet, 0, 3, 1); //设置第0、1、2、3行为一组，序号1
xlsx_support.groupCols(worksheet, 0, 3, 1); //设置第0、1、2、3列为一组，序号1
```

### ·设置颜色
**说明**：如有需要设置表格颜色，可按以下方式设置
```javascript
//设置单元格颜色
xlsx_support.setCellsStyle(worksheet, "A2:C2", {fill:{fgColor : { rgb : "E8F3A8"}}});
//设置字体颜色
xlsx_support.setCellsStyle(worksheet, "A2:C2", {fill:{fgColor : { rgb : "E8F3A8"}}});
```

### ·设置公式
**说明**：如有需要设置表格公式，可按以下方式设置
```javascript
XLSX.utils.sheet_set_array_formula(worksheet, range, f);
//或者
xlsx_support.setFormula(worksheet, range, f);
```
