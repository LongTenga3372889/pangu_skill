# MarmotWebHookHelper使用文档

> MarmotWebHookHelper是Marmot生态的标准WebHook工具   
> 标准程序的开发过程中，可以组装数据交付到WebHook(仅关心消息内容，消息key即可)   
> Marmot工作台中可根据编码配置具体的WebHook地址，在消息到达时调用该地址    
> WebHook的形式决定了：仅保证大多数场景下可靠，无法避免个别的丢失和重复，请知悉
>
> 常用于各类企业微信自动化通知  
> 一般设计：标准产品推送消息->使用Marmot API发布生成一个API->将API配置在WebHook中   
> 请注意：务必解耦消息组装和消息处理两个部分，前者是标准化的，长期不变的，后者是常常变动的


#### 为什么要使用MarmotWebHookHelper？

*   脚本发送消息，方便修改

*   提供消息发送间隔，防止消息轰炸

*   提供鉴权方式，可手动鉴权

*   格式规范，步骤明确

[如果不想使用MarmotWebHookHelper点这里](#附：如果你觉得使用marmotwebhookhelper过于繁琐，也可以直接请求微信机器人webhook地址)

#### 1. 在配置表中配置相关属性

类型：消息类型，用于在后端确定发送的是哪种消息

地址：请求该地址，由响应端发送机器人消息。（可以自定义接口，推荐使用API发布）

校验码：用于脚本端校验，防止恶意操作

间隔：两条相同信息之间的最短间隔，比如脚本报错提示设置该值为30，当第一条消息发送后，第二条key和type相同的消息至少要在30分钟后才能发送。（key值在后端由使用者自行定义）

### 2. 后端调用代码：

示例：发送脚本报错信息

```java
//消息类型，消息类型需在srm-boot-adaptor中WebHookType进行配置（如有需要请联系研发支持）
WebHookType msgType = WebHookType.MARMOT_SCRIPT_CONTAINER_ERROR;
//key设置为租户+编码+报错信息，保证同一适配器发生的同一错误不会在配置表配置的间隔时间内重复发送
String key = "adaptorError" + tenantNum + adaptorCode + errorMessage;
//需要发送的信息，通过args保存发送到脚本端
Map<String, Object> args = new HashMap<>();
args.put("adaptorCode", adaptorCode);  //适配器编码
args.put("tenantNum", tenantNum);  //租户
args.put("errorMessage", finalResult.getMessage());  //错误信息

//发送信息API
MarmotWebHookHelper.push(msgType, key, args);
```

##### 附：MarmotWebHook的其他使用方法-feign调用
```java
//关键代码
@FeignClient(value = "srm-adaptor", path = "/v1")
public interface SrmAdaptorService {
    
    // webHookType:消息类型,值为WebHookType对象的name,也需在srm-boot-adaptor中WebHookType进行配置（如有需要请联系研发支持）
    @PostMapping("/marmot-webhook/push")
    ResponseEntity<String> push(@RequestParam String webHookType, 
                                @RequestParam String key, 
                                @RequestBody Object inputObj);

}
```

#### 3. 设置消息发送脚本

在API发布中设置发送消息的API

![](../../_helper/images/8.34.14_aeBjWGLVHd.png)

编写发送消息的脚本：

```javascript
//获取校验码
let header = input.header;
let secret = header["x-marmot-token"];  //具体校验过程自定
//以下校验仅供参考
if(secret != "script"){
  throw "校验失败";
}
//获取参数
let body = STD.SAFE_JSON.parse(input.body);
//编辑消息并发送
let url = "https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=7214aa1c-7edf-4fa4-83bc-b2727da0f217";
let msgBody = {};
msgBody.msgtype = "markdown";
msgBody.markdown = {"content":"消息内容"};
STD.HttpClient.doPost(url,{},msgBody);

```

### 附：如果你觉得使用MarmotWebHookHelper过于繁琐，也可以直接请求微信机器人webHook地址

```java
  //json格式的body内容
String jsonArgs = "{" +
                "    \"msgtype\":\"markdown\"," +
                "    \"markdown\":{\"content\":\"消息内容\"}" +
                "}";
HttpHeaders httpHeaders = new HttpHeaders();
httpHeaders.add("Content-Type", "application/json; charset=utf-8");
//请求头和参数设置
HttpEntity<String> stringHttpEntity = new HttpEntity<>(jsonArgs, httpHeaders); 
//url是企业微信提供的机器人webhook地址  
String url = "https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=7214aa1c-7edf-4fa4-83bc-b2727da0f217";
restTemplate.postForEntity(url, stringHttpEntity, String.class);
```
